Аналог данной функции при использовании Automation - метод [ksDocument2D::ksSetTextLineAlign](ksdocument2d_kssettextlinealign.html).

Синтаксис:

int ksSetTextLineAlign (unsigned char align);

Входной параметр:

align | \- признак выравнивания: 0 - по левому краю, 1 - по центру, 2 - по правому краю, 3 - по ширине.  
---|---  
  
Возвращаемое значение:

предыдущий признак выравнивания | \- в случае успешного завершения,  
---|---  
-1 | \- в случае неудачи.  
  
Примечание.

Функция ksSetTextLineAlign должна использоваться внутри блока, т.е. необходимо, чтобы был открытый на редактирование текст. Иначе функция не работает.
