Интерфейс параметров операции вращения.

Иерархия:

IDispatch

[IKompasAPIObject](ikompasapiobject.html)

[IModelObject](imodelobject.html)

[IRotated](irotated.html)

Интерфейс позволяет создавать и редактировать операции вращения. Имеет дополнительный интерфейс [IThinParameters](ithinparameters.html), который можно получить с помощью метода [IUnknown::QueryInterface](recomendation.html).

Примечание:

Интерфейс можно получить с помощью свойства [IRotateds::Rotated](irotateds_rotated.html) и метода [IRotateds::Add](irotateds_add.html) с типом o3d_bossRotated.
