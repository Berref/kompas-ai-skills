Аналог данной функции при использовании Automation - метод [ksDocument2D::ksHatch](ksdocument2d_kshatch.html).

Синтаксис:

int Hatch (unsigned int style,

double ang,

double step,

double width,

double x0, double y0);

Входные параметры:

style | \- [стиль штриховки](hstyles.html),  
---|---  
angle | \- угол штриховки в градусах,  
step | \- шаг штриховки,  
width | \- ширина полосы штрихования вдоль границы штриховки,  
x0, y0 | \- координаты начальной точки штриховки.  
  
Возвращаемое значение:

1 | \- в случае успешного завершения,  
---|---  
0 | \- в случае неудачи.  
  
Примечание:

1\. Все следующие далее до вызова функции [EndObj](endobj.html) геометрические примитивы определяют границы штриховки (внешние и внутренние). Порядок определения элементов границы является произвольным. Функция EndObj возвращает указатель на объект Штриховка.

2\. Функция устарела, рекомендуется вместо нее использовать функцию [HatchEx](hatchex.html).
