Иерархия:

IDispatch

[ICutViewParam](icutviewparam.html)

Описание:

Интерфейс позволяет задавать и получать параметры разреза вида.

Примечание:

Интерфейс является дополнительным к интерфейсу вида [IView](iview.html) для видов всех типов, кроме системного.
