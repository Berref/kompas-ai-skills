Интерфейс контейнера объектов вспомогательной геометрии.

Иерархия:

IDispatch

[IAuxiliaryGeomContainer](iauxiliarygeomcontainer.html)

Описание:

Позволяет получить коллекции объектов вспомогательной геометрии (ЛСК, сплайн и т.д).

Примечание:

Дополнительный интерфейс компонента. Данный интерфейс можно получить у компонента [IPart7](ipart7.html) посредством вызова метода [IUnknown::QueryInterface (const GUID far& iid, void** pif)](recomendation.html).
