# CornerParam - Структура параметров скругленных (или усеченных) углов прямоугольников и правильных многоугольников

[Структуры параметров и константы](3d_define.html) > [Структуры параметров графических объектов ](bk1735830.html) |  Scroll [ [ [ ](structcurvepattern.html "К следующему разделу")](bk1735830.html "На уровень выше")](structconicarcparam.html "К предыдущему разделу")  
---|---  
  
Аналог данных параметров при использовании Automation - интерфейс [ksCornerParam](kscornerparam.html).

int | index | индекс (номер) угла (0, 1, 2, ...),  
---|---|---  
unsigned char | fillet | признак фаски/скругления: 0 - фаска, 1 -скругление,  
double | l1 | длина фаски первого сегмента или радиус скругления,  
double | l2 | длина фаски второго сегмента.  
  
Примечание:

Данная структура используется внутри структуры параметров прямоугольника [RectangleParam](structrectangleparam.html) или правильного многоугольника [RegularPolygonParam](structregularpolygonparam.html) для задания скруглений и фасок на определенных углах этого многоугольника. Если скругления и фаски не нужны, то структура CornerParam не используется.
