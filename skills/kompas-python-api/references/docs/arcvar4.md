# По точке и углу

---|---  
  
Требуется задать следующие параметры:

•координаты центра ([XC](iarc_xc.html); [YC](iarc_yc.html)),

•координаты начальной ([X1](iarc_x1.html); [Y1](iarc_y1.html)) или конечной ([X2](iarc_x2.html); [Y2](iarc_y2.html)) точек,

•угол между осью X и направлением на первую точку [Angle1](iarc_angle1.html), если заданы координаты точки 2

•угол между осью X и направлением на вторую точку [Angle2](iarc_angle2.html), если заданы координаты точки 1

•направление [Direction](iarc_direction.html).
