# Колонка табличного атрибута (Интерфейс ksColumnInfoParam)

Интерфейс параметров столбца табличного атрибута.

Аналог данных параметров при использовании API экспортных функций - [ColumnInfo](structcolumninfo.html).

Примечание:

1\. Перед использованием указатель на интерфейс должен быть определен с помощью метода [KompasObject::GetParamStruct](kompasobject_getparamstruct.html) с параметром ko_ColumnInfoParam.

2\. Параметры интерфейса могут быть получены с помощью методов [ksAttributeObject::ksGetAttrColumnInfo](ksattributeobject_ksgetattrcolumninfo.html), [ksAttributeTypeParam::GetColumns](ksattributetypeparam_getcolumns.html).

Смотрите также [KompasObject](kompasobject.html)
