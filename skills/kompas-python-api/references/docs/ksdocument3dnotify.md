Позволяют контролировать редактирование документа-модели.

В Automation источник событий для подписки [Document3DNotify](document3dnotify.html) можно получить при помощи метода [ksDocument3D::GetDocument3DNotify](ksdocument3d_getdocument3dnotify.html).

В COM источником для подписки является документ-модель.
