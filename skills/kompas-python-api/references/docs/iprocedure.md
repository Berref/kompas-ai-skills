Примечание:

1\. Интерфейс позволяет получить имя, идентификатор команды, ее папку в библиотеке, выполнить команду.

2\. Данный интерфейс может быть получен у интерфейса коллекции команд [IProcedures](iprocedures.html) с помощью свойств [IProcedures::Item](iprocedures_item.html), [IProcedures::ItemByID](iprocedures_itembyid.html).
