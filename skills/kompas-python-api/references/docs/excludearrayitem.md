Синтаксис:

int ExcludeArrayItem (reference p, int numb);

Входной параметр:

p | \- указатель на массив,  
---|---  
numb | \- номер элемента массива, нумерация начинается с 0.  
  
Возвращаемое значение:

1 | \- в случае успеха,  
---|---  
0 | \- в случае неудачи.
