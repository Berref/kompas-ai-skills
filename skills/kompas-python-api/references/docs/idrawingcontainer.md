Интерфейс контейнера объектов вида графического документа.

Иерархия:

IDispatch

[IDrawingContainer](idrawingcontainer.html)

Описание:

Позволяет получить коллекции объектов, которые входят в состав вида графического документа или его объекта.

Примечание:

Дополнительный интерфейс вида. Данный интерфейс можно получить у вида [IView](iview.html) посредством вызова метода [IUnknown::QueryInterface (const GUID far& IID, void** pif)](recomendation.html).
