Аналог данной функции при использовании Automation - метод [ksDataBaseObject::ksCreateDB](ksdatabaseobject_kscreatedb.html).

Синтаксис:

reference CreateDB( char *s );

Входной параметр:

s | \- тип базы данных: TXT_DB - база данных [текстового формата](loa.html), ODBC_DB - база данных, доступная через интерфейс [ODBC](odbc.html).  
---|---  
  
Возвращаемое значение:

указатель на блок заголовка базы данных | \- в случае успешного завершения,  
---|---  
0 | \- в случае неудачи.  
  
Примечание:

1\. Функция позволяет открыть БД. Одновременно может быть открыто несколько БД.

2\. При использовании Unicode следует использовать функцию [CreateDBW](createdbw.html).
