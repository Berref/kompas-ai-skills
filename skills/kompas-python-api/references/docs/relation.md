Аналог данной функции при использовании Automation - метод [ksDataBaseObject::ksRelation.](ksdatabaseobject_ksrelation.html)

Синтаксис:

reference Relation (reference bd);

Входной параметр:

bd | \- указатель на объект БД.  
---|---  
  
Возвращаемое значение:

указатель на отношение | \- в случае успешного завершения,  
---|---  
0 | \- в случае неудачи.  
  
Примечание:

Отношение характеризует один запрос и представляет собой описание памяти, необходимой для размещения очередной записи выборки, выполняемого функцией [ReadRecord](readrecord.html). Является составным объектом, каждое поле которого описывает тип и имя поля (колонки) в таблице базы данных. Имя действительно только в случае работы с текстовым файлом, так как при обмене через ODBC-интерфейс имена уже описаны в блоке заголовка. Количество отношений, определенных для базы данных, не ограничивается.
