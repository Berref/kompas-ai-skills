Интерфейс Nurbs-поверхности.

Иерархия:

[IKompasAPIObject](ikompasapiobject.html)

[IModelObject](imodelobject.html)

[INurbsSurface](inurbssurface.html)

Описание:

Интерфейс позволяет создать NURBS-поверхность по заданной поверхности или по параметрам NURBS-поверхности. Есть возможность ограничить поверхность набором контуров.

Примечание:

Интерфейс можно получить с помощью свойства [INurbsSurfaces::NurbsSurface](inurbssurfaces_nurbssurface.html) и метода [INurbsSurfaces::Add](inurbssurfaces_add.html).
