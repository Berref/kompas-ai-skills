Интерфейс коллекции настроек блоков дополнительных (вложенных) разделов.

Иерархия:

[IKompasAPIObject](ikompasapiobject.html)

[IKompasCollection](ikompascollection.html)

[IAdditionalBlockTunings](iadditionalblocktunings.html)

Описание:

Управляет массивом интерфейсов [IAdditionalBlockTuning](iadditionalblocktuning.html).

Примечание:

1\. Интерфейс настроек блоков дополнительных разделов можно получить от интерфейса настроек спецификации [ISpecificationTuning](ispecificationtuning.html) с помощью свойства [ISpecificationTuning::AdditionalBlocks](ispecificationtuning_additionalblocks.html).

2\. Интерфейс коллекции настроек блоков вложенных разделов можно получить от интерфейса настроек раздела спецификации [ISpecificationTuningSection](ispecificationtuningsection.html) с помощью свойства [ISpecificationTuningSection::AdditionalBlocks](ispecificationtuningsection_additionalblocks.html).
