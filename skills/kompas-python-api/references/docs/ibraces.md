Описание:

Интерфейс позволяет получить доступ к фигурным скобкам на чертеже.

Примечание:

Получить интерфейс коллекции фигурных скобок можно, используя метод контейнера объектов СПДС [IBuildingContainer::Braces](ibuildingcontainer_braces.html).
