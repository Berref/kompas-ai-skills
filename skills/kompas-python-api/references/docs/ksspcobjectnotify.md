Позволяют контролировать редактирование объектов спецификации.

В Automation источник событий для подписки [SpcObjectNotify](spcobjectnotify.html) можно получить при помощи метода [ksSpecification::GetSpcObjectNotify](ksspecification_getspcobjectnotify.html).

В COM источником для подписки является документ (графический, документ-модель, спецификация).
