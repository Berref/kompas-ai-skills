---|---

Значения свойства:

TRUE | \- учитывать ширину,  
---|---  
FALSE | \- не учитывать.  
  
Примечание.

Позволяет считывать и устанавливать признак - "учитывать ширину". Свойство доступно при включенной опции "использовать освобождение сгиба".
