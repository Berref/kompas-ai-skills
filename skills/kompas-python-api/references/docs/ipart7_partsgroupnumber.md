Синтаксис Automation:

PartsGroupNumber = Object.PartsGroupNumber | Получить свойство ([* ](1.html))  
---|---  
Object.PartsGroupNumber = PartsGroupNumber | Установить свойство ([* ](1.html))  
PartsGroupNumber = Object.GetPartsGroupNumber() | Получить свойство ([**](2.html))  
Object.SetPartsGroupNumber( PartsGroupNumber ) | Установить свойство ([**](2.html))  
  
Синтаксис COM:

Object.get_PartsGroupNumber( &PartsGroupNumber ) | Получить свойство  
---|---  
Object.put_PartsGroupNumber( PartsGroupNumber ) | Установить свойство  
  
Примечание:

Вставки, объединенные в группу, в спецификации будут иметь одинаковый номер позиции.

В группу могут объединяться вставки из разных исполнений документа.
