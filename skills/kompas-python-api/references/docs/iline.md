Описание:

Интерфейс позволяет получить и задать свойства прямой линии.

Примечание:

1\. Интерфейс можно получить, используя свойство коллекции линий [ILines::Line](ilines_line.html) или метод [ILines::Add](ilines_add.html).

2\. После задания параметров линии требуется вызвать метод [IDrawingObject::Update](idrawingobject_update.html).
