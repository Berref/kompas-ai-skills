Примечание:

1\. Интерфейс позволяет получить указатель на объект для которого посылается данное событие. Например, выбор материала и обозначения доступны для верхнего компонента, вставки и тела.

2\. Интерфейс можно получить с помощью метода [IDocument3D::GetDocument3DNotifyResult](ksdocument3d_getdocument3dnotifyresult.html) или [ksDocument3D::GetDocument3DNotifyResult](ksdocument3d_getdocument3dnotifyresult.html).
