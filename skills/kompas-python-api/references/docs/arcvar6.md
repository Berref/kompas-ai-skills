Требуется задать следующие параметры:

•координаты начальной ([X1](iarc_x1.html); [Y1](iarc_y1.html)) и конечной ([X2](iarc_x2.html); [Y2](iarc_y2.html)) точек,

•угол между осью X и направлением на первую [Angle1](iarc_angle1.html) или вторую точку [Angle2](iarc_angle2.html),

•направление [Direction](iarc_direction.html).
