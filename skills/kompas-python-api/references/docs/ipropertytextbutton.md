Примечание:

1\. Данный интерфейс можно получить через коллекцию элементов управления Панели свойств [IPropertyControls](ipropertycontrols.html).

2\. При нажатии на кнопку вызывается событие [ksPropertyManagerNotify::ControlCommand](kspropertymanagernotify_controlcommand.html).

3\. Элемент управления работает как обычная кнопка со стилем BS_PUSHBUTTON.
