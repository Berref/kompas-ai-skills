Если в библиотеке при вызове диалога параметр parent передан как NULL, то возможна ситуация, когда диалог не санкционированно закроется. Для предотвращения подобных случаев параметру parent нужно задавать значение дескриптора главного окна КОМПАС. Значение дескриптора можно получить, используя функции [GetHWindow](gethwindow.html) или [KompasObject::ksGetHWindow](kompasobject_ksgethwindow.html).

Для библиотек, написанных на Visual C++, которые имеют свой WinApp, нужно использовать:

CWnd parent;

parent.Attach((HWND)::GetHWindow());

.... работа с диалогом

parent.Detach();

//---

Для библиотек без WinApp можно использовать:

CWnd::FromHandlePermanent((HWND)::GetHWindow());
