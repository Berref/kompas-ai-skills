Интерфейс менеджера вкладок окна документа.

Описание:

Дополнительный интерфейс для [IDocumentFrame](idocumentframe.html).

Данный интерфейс можно получить у интерфейса IDocumentFrame посредством вызова метода [IUnknown::QueryInterface (const GUID far& IID, void** pif)](recomendation.html).

Примечание:

1\. Позволяет создавать вкладку в окне дерева документа.

2\. Добавить вкладку можно в окно чертежа, 3D модели и сборки.

3\. Для создания закладки используется метод [AddTab](iframetreesmanager_addtab.html).
