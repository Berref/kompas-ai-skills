Описание:

Интерфейс можно получить с помощью следующих методов:

•[IToleranceParam::Table](itoleranceparam_table.html) у интерфейса параметров обозначения допуска формы,

•метода [IUnknown::QueryInterface](recomendation.html) у следующих интерфейсов:

•интерфейса таблицы на чертеже [IDrawingTable](idrawingtable.html),

•допуска формы [ITolerance](itolerance.html) и [ITolerance3D](itolerance3d.html).
