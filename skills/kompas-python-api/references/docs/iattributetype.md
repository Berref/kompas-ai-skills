Интерфейс параметров типа атрибута.

Иерархия:

[IKompasAPIObject](ikompasapiobject.html)

[IAttributeType](iattributetype.html)

Примечание:

1\. Интерфейс позволяет задавать параметры типа атрибута.

2\. Интерфейс можно получить следующими способами:

•у менеджера типа атрибутов с помощью методов [IAttrTypeMng::CreateAttrType](iattrtypemng_createattrtype.html), [IAttrTypeMng::GetAttrType](iattrtypemng_getattrtype.html), [IAttrTypeMng::ChoiceAttrTypes](iattrtypemng_choiceattrtypes.html),

•у атрибута с помощью свойства [IAttribute::AttributeType](iattribute_attributetype.html).
