Справка в приложении реализуется с помощью интерфейса [IProceduresLibrary](iprocedureslibrary.html).

[id(), helpstring("Открыть справку приложения."), helpcontext()]

HRESULT OpenHelp( [in]long HelpId, [out, retval] VARIANT_BOOL* PVal);

Структура файлов

Для корректной работы справки приложение должно иметь следующие файлы:

•ini-файл приложения,  
см. раздел [Порядок именования и расположения ini-файлов](name_for_ini.html);

•базу данных соответствия идентификатора команды и страницы справки (*.db),   
см. разделы [Порядок именования и расположения файлов справки](name_help.html) и [База данных соответствия номеров команд и страниц справки](value_base.html);

•архив со справкой (*.zip).
