Интерфейс вспомогательного элемента Панели свойств. Набор команд элемента управления.

Иерархия:

IDispatch

[IPropertyToolBar](ipropertytoolbar.html)

Описание:

Позволяет управлять командами элемента управления на Панели свойств.

Примечание:

Данный интерфейс можно получить у интерфейсов [IPropertyGrid](ipropertygrid.html) или [IPropertyEditList](ipropertyeditlist.html) посредством вызова метода [IUnknown::QueryInterface (const GUID far& iid, void** pif)](recomendation.html).
