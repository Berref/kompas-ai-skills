Интерфейс аннотационных объектов.

Иерархия:

IDispatch

[IAnnotativeObject](iannotativeobject.html)

Описание:

Интерфейс позволяет задать параметры аннотационного объекта.

Примечание:

Интерфейс можно получить у контейнера аннотационных объектов с помощью свойства [IAnnotativeContainer::Item](iannotativecontainer_item.html) и методов [IAnnotativeContainer::Add](iannotativecontainer_add.html) и [IAnnotativeContainer::CreateByGeomObject](iannotativecontainer_createbygeomobject.html).
