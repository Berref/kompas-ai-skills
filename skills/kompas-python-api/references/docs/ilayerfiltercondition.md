Интерфейс условия фильтрации слоев.

Иерархия:

[IKompasAPIObject](ikompasapiobject.html)

[ILayerFilterCondition](ilayerfiltercondition.html)

Описание:

Условия фильтрации используются для формирования состава динамической группы слоев.

Примечание:

Данный интерфейс можно получить через коллекцию условий фильтрации слоев [ILayerFilterConditions](ilayerfilterconditions.html) с помощью свойства [ILayerFilterConditions::Item](ilayerfilterconditions_item.html).
