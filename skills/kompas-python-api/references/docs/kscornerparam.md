Интерфейс параметров скругленных (или усеченных) углов для прямоугольников и правильных многоугольников.

Аналог данных параметров при использовании API экспортных функций - [CornerParam](structcornerparam.html).

Примечание:

Интерфейс используется для задания скруглений и фасок на определенных углах правильного многоугольника [ksRegularPolygonParam](ksregularpolygonparam.html) и прямоугольника [ksRectangleParam](ksrectangleparam.html).

Указатель на интерфейс можно получить при помощи метода [KompasObject::GetParamStruct](kompasobject_getparamstruct.html).

Смотрите также: [KompasObject](kompasobject.html)
