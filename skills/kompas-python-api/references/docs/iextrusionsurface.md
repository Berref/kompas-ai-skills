Интерфейс позволяет создавать и редактировать поверхности выдавливания.

Примечание:

Интерфейс можно получить с помощью свойства [IExtrusions::Extrusion](iextrusions_extrusion.html) и метода [IExtrusions::Add](iextrusions_add.html) с типом o3d_ExtrusionSurface.
