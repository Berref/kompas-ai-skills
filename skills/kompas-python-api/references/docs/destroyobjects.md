# ksDestroyObjects - Разрушить присланные составные объекты

[API экспортных функций](export_function.html) > [Редактирование графических объектов ](cn1712096.html) > [Функции редактирования объектов чертежа ](draft_edit_fncts_common.html) |  Scroll [ [ [ ](kseditviewobject.html "К следующему разделу")](draft_edit_fncts_common.html "На уровень выше")](kscopyobjex.html "К предыдущему разделу")  
---|---  
  
Аналог данной функции при использовании Automation - метод [ksDocument2D::ksDestroyObjects](ksdocument2d_ksdestroyobjects.html).

Синтаксис:

long ksDestroyObjects(reference p).

Входной параметр:

p | \- указатель на объект, вид, слой или группу.  
---|---  
  
Возвращаемое значение:

1 | \- в случае успешного завершения,  
---|---  
0 | \- в случае неудачи.  
  
Примечание:

1\. Разрушает не только составные объекты (макроэлементы, вставки фрагментов, эквидистанты, прямоугольники, контуры), но и виды (если у них есть связь с моделью).

2\. Функция работает только для документов, открытых в «видимом» режиме.
