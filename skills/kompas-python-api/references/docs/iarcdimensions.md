Интерфейс коллекции размеров дуг окружностей.

Иерархия:

[IKompasAPIObject](ikompasapiobject.html)

[IKompasCollection](ikompascollection.html)

[IDrawingObjects](idrawingobjects.html)

[IArcDimensions](iarcdimensions.html)

Описание:

Интерфейс позволяет получать и создавать размеры дуг окружностей.

Примечание:

Данный интерфейс можно получить у контейнера условных обозначений, используя свойство [ISymbols2DContainer::ArcDimensions](isymbols2dcontainer_arcdimensions.html).
