Аналог данной функции при использовании Automation - метод [ksDocument2D::ksLine](ksdocument2d_ksline.html).

Синтаксис:

reference Line (double x, double y,

double ang);

Входные параметры:

x, y | \- координаты точки,  
---|---  
ang | \- угол наклона прямой.  
  
Возвращаемое значение:

указатель на графический объект Линия. | \- в случае успеха,  
---|---  
0 | \- в случае неудачи.  
  
Примечание:

Объект создается в текущем слое текущего вида и используется для вспомогательных построений.
