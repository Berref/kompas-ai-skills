Тип данных: BOOL

Синтаксис Automation:

ShowScale = iObject.ShowScale | Получить свойство ([* ](1.html))  
---|---  
iObject.ShowScale = ShowScale | Установить свойство ([* ](1.html))  
ShowScale = iObject.GetShowScale() | Получить свойство ([**](2.html))  
iObject.SetShowScale (ShowScale) | Установить свойство ([**](2.html))  
  
Синтаксис COM:

iObject->get_ShowScale( &ShowScale ) | Получить свойство  
---|---  
iObject->put_ShowScale( ShowScale ) | Установить свойство  
  
Примечание:

Если свойство возвращает TRUE, в обозначении вида включается масштаб.

Если FALSE, масштаб из обозначения выключается.
