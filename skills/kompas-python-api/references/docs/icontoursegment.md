Интерфейс сегмента контура.

Иерархия:

IDispatch

[IKompasAPIObject](ikompasapiobject.html)

[IContourSegment](icontoursegment.html)

Описание:

Интерфейс позволяет редактировать сегмент контура.

Примечание:

1\. Интерфейс можно получить у интерфейса контура с помощью свойства [IContour::Segment](icontour_segment.html) или метода [IContour::AddSegment](icontour_addsegment.html).

2\. Имеет следующие дополнительные интерфейсы, которые можно получить с помощью метода [IUnknown::QueryInterface](recomendation.html):

•[IContourLineSegment](icontourlinesegment.html),

•[IContourArc](icontourarc.html).
