Интерфейс можно получить у интерфейса коллекции поверхностей по сети точек с помощью свойства [IMeshPointsSurfaces::MeshPointsSurface](imeshpointssurfaces_meshpointssurface.html) или метода [IMeshPointsSurfaces::Add](imeshpointssurfaces_add.html).

С помощью метода [IUnknown::QueryInterface](recomendation.html) у интерфейса можно получить интерфейс подчиненного объекта ЛСК [ILocalCSObject](ilocalcsobject.html).
