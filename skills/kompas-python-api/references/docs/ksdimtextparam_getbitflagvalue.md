Синтаксис Automation:

BOOL GetBitFlagValue (long bitFlag);

Входной параметр:

bitFlag | \- битовый флаг, характеризующий определенный [признак размерной надписи](dmodes.html).  
---|---  
  
Возвращаемое значение:

TRUE | \- данный битовый флаг включен,  
---|---  
FALSE | \- данный битовый флаг выключен.  
  
См. также свойство [bitFlag](ksdimtextparam_bitflag.html)
