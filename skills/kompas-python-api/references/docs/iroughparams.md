Интерфейс параметров обозначения шероховатости.

Иерархия:

IDispatch

[IRoughParams](iroughparams.html)

Описание:

1\. Является дополнительным интерфейсом для 2D и 3D обозначений шероховатости.

2\. Позволяет задать и получить параметры обозначения шероховатости.

3\. Интерфейс можно получить с помощью метода [IUnknown::QueryInterface](recomendation.html) у интерфейсов [IRough3D](irough3d.html) или [IRough](irough.html).
