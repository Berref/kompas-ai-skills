[IArcDimensions3D](iarcdimensions3d.html)

Примечание:

Интерфейс позволяет получить и создавать размеры дуг окружностей в 3D документе.

Данный интерфейс можно получить у контейнера условных обозначений, используя свойство [ISymbols3DContainer::ArcDimensions3D](isymbols3dcontainer_arcdimensions3d.html).

Версия: Компас v20
