Интерфейс таблицы переменных.

Иерархия:

[IKompasAPIObject](ikompasapiobject.html)

[IVariableTable](ivariabletable.html)

Описание:

Позволяет считывать, изменять, добавлять параметры таблицы переменных компонента, применять параметры из таблицы переменных к компоненту.

Примечание:

1\. Данный интерфейс можно получить:

•от интерфейса [IPart7](ipart7.html), используя свойство [IPart7::VariableTable](ipart7_variabletable.html),

•от интерфейса [IKompasDocument2D1](ikompasdocument2d1.html), используя свойство [IKompasDocument2D1::VariableTable](ikompasdocument2d1_variabletable.html).

2\. Доступно редактирование таблицы переменных только верхнего компонента.
