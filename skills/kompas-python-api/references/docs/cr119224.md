В Компас v20 появилась возможность наследования от интерфейсов прикладной библиотеки.

Добавлена библиотека типов интерфейсов KompasLibrary.tlb с описанием нового дуального интерфейса прикладной ActiveX библиотеки [IKompasLibrary](ikompaslibrary.html) и интерфейса [ksKompasLibrary](kskompaslibrary.html), который соответствует старому описанию функций для ActiveX библиотек.

В библиотеке можно реализовать наследование от нового или старого варианта интерфейсов.
