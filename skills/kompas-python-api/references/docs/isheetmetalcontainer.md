Интерфейс контейнера объектов гибки.

Иерархия:

IDispatch

[ISheetMetalContainer](isheetmetalcontainer.html)

Описание:

ISheetMetalContainer является дополнительным к интерфейсу [IPart7](ipart7.html) и позволяет работать с коллекциями объектов гибки (листовые тела, сгибы и т.д). Данный интерфейс можно получить от IPart7 посредством вызова метода [IUnknown::QueryInterface (const GUID far& iid, void** pif)](recomendation.html).
