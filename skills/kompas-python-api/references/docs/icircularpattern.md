Интерфейс используется для операций:

o3d_circularCopy | 36 | Массив по концентрической сетке  
---|---|---  
o3d_circPartArray | 38 | Массив компонентов по концентрической сетке для сборки  
o3d_AuxCircularCopy | 505 | Массив вспомогательной геометрии по концентрической сетке  
o3d_BodiesCircularCopy | 529 | Массив тел по концентрической сетке  
  
Интерфейс можно получить в коллекции массивов [IFeaturePatterns](ifeaturepatterns.html).
