Интерфейс группы (постоянной, временной, именованной).

Иерархия:

IDispatch

[IKompasAPIObject](ikompasapiobject.html)

[IDrawingGroup](idrawinggroup.html)

Описание:

Интерфейс позволяет задавать параметры группы (постоянной, временной или именованной).

Примечание:

Интерфейс можно получить у коллекции групп, используя свойство [IDrawingGroups::Item](idrawinggroups_item.html) или метод [IDrawingGroups::Add](idrawinggroups_add.html) или у дополнительного интерфейса документа 2D с помощью свойства [IKompasDocument2D1::CurrentGroup](ikompasdocument2d1_currentgroup.html).
