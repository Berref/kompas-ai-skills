Иерархия:

IDispatch

[IKompasAPIObject](ikompasapiobject.html)

[IDrawingObject](idrawingobject.html)

[IRectangle](irectangle.html)

Описание:

Интерфейс позволяет задавать параметры прямоугольника.

Примечание:

1\. Интерфейс можно получить у коллекции прямоугольников, используя свойство [IRectangles::Rectangle](irectangles_rectangle.html) или метод [IRectangles::Add](irectangles_add.html).

2\. После задания параметров прямоугольника требуется вызвать метод [IDrawingObject::Update](idrawingobject_update.html).
