Синтаксис Automation:

BOOL SetpMathPoint (LPDISPATCH pMathPoint);

Входной параметр:

pMathPoint | \- указатель на интерфейс динамического массива [ksDynamicArray](ksdynamicarray.html) типа POINT_ARR.  
---|---  
  
Возвращаемое значение:

TRUE | \- в случае удачного завершения.  
---|---  
  
Примечание:

Массив точек ломаной состоит из начальной точки, точек излома и конечной точки.
