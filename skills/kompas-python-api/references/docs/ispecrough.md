Иерархия:

IDispatch

[IKompasAPIObject](ikompasapiobject.html)

[ISpecRough](ispecrough.html)

Описание:

Интерфейс позволяет задавать и получать параметры неуказанной шероховатости.

Примечание:

Интерфейс можно получить у интерфейса чертежа с помощью свойства [IDrawingDocument::SpecRough](idrawingdocument_specrough.html).
