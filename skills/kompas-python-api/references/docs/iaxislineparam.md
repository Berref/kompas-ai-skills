Параметры осевой линии или обозначения центра.

Иерархия:

IDispatch

[IKompasAPIObject](ikompasapiobject.html)

[IAxisLineParam](iaxislineparam.html)

Описание:

Интерфейс позволяет задавать и получать параметры осевой линии.

Примечание:

Интерфейс является дополнительным к интерфейсу осевой линии [IAxisLine](iaxisline.html) и интерфейсу обозначения центра [ICentreMarker](icentremarker.html).
