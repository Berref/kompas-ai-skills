Аналог данной функции при использовании Automation - метод [ksDocument2D::ksPhantomShowHide](ksdocument2d_ksphantomshowhide.html).

Синтаксис:

int ksPhantomShowHide (unsigned char type);

Входные параметры:

type | \- признак отрисовки фантома: 1 - включить, 0 - выключить.  
---|---  
  
Возвращаемое значение:

1 | \- в случае успешного завершения,  
---|---  
0 | \- в случае неудачи.
