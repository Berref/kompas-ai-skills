Интерфейс позволяет получать и создавать отрезки в трехмерном пространстве.

Интерфейс можно получить в контейнере вспомогательной геометрии с помощью свойства [IAuxiliaryGeomContainer::LineSegments3D](iauxiliarygeomcontainer_linesegments3d.html).
