Интерфейс выносной надписи к многослойным конструкциям.

Иерархия:

[IKompasAPIObject](ikompasapiobject.html)

[IDrawingObject](idrawingobject.html)

[IMultiTextLeader](imultitextleader.html)

Описание:

Интерфейс позволяет получить доступ к выносной надписи к многослойным конструкциям. С помощью интерфейса можно получить и отредактировать параметры объекта.

Примечание:

1\. Получить интерфейс можно, используя свойство интерфейса коллекции [IMultiTextLeaders::MultiTextLeader](imultitextleaders_multitextleader.html) или метод [IMultiTextLeaders::Add](imultitextleaders_add.html).

2\. Новые параметры вступят в силу после вызова метода [IDrawingObject::Update](idrawingobject_update.html).
