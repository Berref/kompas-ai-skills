Тип данных: указатель на интерфейс [IModelObject](imodelobject.html)

Синтаксис Automation:

Axis = Object.Axis | Получить свойство ([* ](1.html))  
---|---  
Object.Axis = Axis | Установить свойство ([**](2.html))  
Object.Axis = Axis | Получить свойство ([**](2.html))  
Object.SetAxis( Axis ) | Установить свойство ([**](2.html))  
  
Синтаксис COM:

Object.get_Axis( &Axis ) | Получить свойство  
---|---  
Object.put_Axis( Axis ) | Установить свойство  
  
Свойство позволяет устанавливать и получать объект, задающий ось вращения. Ось может являться кривой 3D, ребром или браться из эскиза.

Примечание:

Объект, задающий ось, должен быть прямолинейным. Если используется ось из эскиза, то она должна быть изображена отрезком со стилем линии Осевая или объектом Осевая линия.
