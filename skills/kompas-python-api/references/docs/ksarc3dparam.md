Интерфейс параметров трехмерной дуги.

ksArc3dParam | \- интерфейс Automation  
---|---  
IArc3dParam | \- интерфейс COM  
  
Описание:

Трехмерная дуга определяется положением плоскости, в которой эта дуга лежит, углом раствора и радиусом. Угол раствора отсчитывается от оси OX плоскости дуги.

Примечание:

Данный интерфейс может быть получен с использованием метода интерфейса [ksCurve3D::GetCurveParam](kscurve3d_getcurveparam.html).
