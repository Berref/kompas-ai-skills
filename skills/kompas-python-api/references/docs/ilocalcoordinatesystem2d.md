Интерфейс локальной системы координат.

Иерархия:

IDispatch

[IKompasAPIObject](ikompasapiobject.html)

[ILocalCoordinateSystem2D](ilocalcoordinatesystem2d.html)

Интерфейс локальных систем координат, позволяющий получить доступ к ее свойствам, таким как имя, положение в системе координат вида, обозначения осей координат.

Примечание:

Данный интерфейс можно получить с помощью свойств [ItemILocal](ilocalcoordinatesystems2d_item.html) и [CurrentILocal](ilocalcoordinatesystems2d_current.html), а также метода [AddILocal](ilocalcoordinatesystems2d_add.html) интерфейса [ILocalCoordinateSystems2D](ilocalcoordinatesystems2d.html).
