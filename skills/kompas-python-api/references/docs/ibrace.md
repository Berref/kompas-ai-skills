Описание:

Интерфейс позволяет получать и изменять свойства фигурных скобок.

Примечание:

Получить интерфейс марки можно, используя свойство интерфейса коллекции фигурных скобок [IBraces::Brace](ibraces_brace.html) или метод [IBraces::Add](ibraces_add.html).
