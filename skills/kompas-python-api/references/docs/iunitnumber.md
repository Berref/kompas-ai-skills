Интерфейс номера узла.

Иерархия:

[IKompasAPIObject](ikompasapiobject.html)

[IDrawingObject](idrawingobject.html)

[IUnitNumber](iunitnumber.html)

Описание:

Интерфейс позволяет получать и изменять свойства номеров узлов на чертеже.

Примечание:

Интерфейс можно получить с помощью метода коллекции номеров узла [IUnitNumbers::Add](iunitnumbers_add.html) или свойства [IUnitNumbers::UnitNumber](iunitnumbers_unitnumber.html).
