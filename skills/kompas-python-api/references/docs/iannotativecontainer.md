Интерфейс контейнера аннотационных объектов.

Иерархия:

IDispatch

[IAnnotativeContainer](iannotativecontainer.html)

Описание:

Интерфейс позволяет создавать и получать аннотационные объекты.

Примечание:

Интерфейс является дополнительным к интерфейсу макрообъекта [IMacroObject](imacroobject.html). Данный интерфейс можно получить посредством вызова метода [IUnknown::QueryInterface (const GUID far& IID, void** pif)](recomendation.html).
