Синтаксис Automation:

long ksSetLightObjType( reference ref, long light );

Входные параметры:

ref | \- указатель на объект,  
---|---  
light | \- light=1 - красный или light=0 - зеленый.  
  
Возвращаемое значение:

1 | \- в случае успешного завершения,  
---|---  
0 | \- в случае неудачи.
