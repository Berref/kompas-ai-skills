Аналог данной функции при использовании Automation - метод [KompasObject::ksIsEnableTaskAccess](kompasobject_ksisenabletaskaccess.html).

Синтаксис:

int IsEnableTaskAccess ();

Возвращаемое значение:

0 | \- доступ к задаче со стороны пользователя запрещен,  
---|---  
1 | \- доступ к задаче со стороны пользователя разрешен.
