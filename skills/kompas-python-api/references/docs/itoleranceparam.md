Интерфейс параметров обозначения допуска формы.

Иерархия:

IDispatch

[IToleranceParam](itoleranceparam.html)

Описание:

1\. Является дополнительным интерфейсом для 2D и 3D обозначений допуска формы.

2\. Позволяет задать и получить параметры обозначения допуска формы.

3\. Интерфейс можно получить с помощью метода [IUnknown::QueryInterface](recomendation.html) у интерфейсов [ITolerance](itolerance.html) и [ITolerance3D](itolerance3d.html).
