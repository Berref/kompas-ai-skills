# Значения параметра pObj

» Нет разделов более высокого уровня « |  Scroll  
---|---  
  
NULL или указатель на интерфейс документа [ksDocument3D](ksdocument3d.html) или [IDocument3D](ksdocument3d.html) | \- выполняется операция с атрибутом у документа,  
---|---  
Указатель на группу объектов дерева [ksFeatureCollection](ksfeaturecollection.html) или [IFeatureCollection](ksfeaturecollection.html) | \- выполняется операция с групповым атрибутом,  
Указатель на объект дерева [ksFeature](ksfeature.html) или [IFeature](ksfeature.html) | \- выполняется операция с атрибутом определенного объекта,  
Указатель на COM-интерфейс из диапазона: o3d_planeXOY...o3d_planeYOZ,o3d_sketch, o3d_axis2Planes...o3d_lastEntityElement-1,o3d_entity | \- выполняется операция с атрибутом у соответствующего ему элемента дерева.
