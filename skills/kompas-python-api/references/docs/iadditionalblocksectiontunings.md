Интерфейс коллекции настроек разделов блока дополнительных (вложенных) разделов.

Иерархия:

[IKompasAPIObject](ikompasapiobject.html)

[IKompasCollection](ikompascollection.html)

[IAdditionalBlockSectionTunings](iadditionalblocksectiontunings.html)

Описание:

Управляет массивом интерфейсов [IAdditionalBlockSectionTuning](iadditionalblocksectiontuning.html). В коллекции разделов доступны все разделы, определенные в стиле спецификации. Настройки разделов, использующихся в блоках, полностью совпадают с настройками соответствующих обычных разделов.

Примечание:

Данный интерфейс может быть получен от интерфейса настройки блока дополнительных (вложенных) разделов [IAdditionalBlockTuning](iadditionalblocktuning.html) с помощью свойства [IAdditionalBlockTuning::Sections](iadditionalblocktuning_sections.html)
