Позволяют контролировать редактирование документа-спецификации.

В Automation источник событий для документа-спецификации [SpcDocumentNotify](spcdocumentnotify.html) можно получить при помощи метода [ksSpcDocument::GetSpcDocumentNotify](ksspcdocument_getspcdocumentnotify.html).

В COM источником для подписки является документ-спецификация.
