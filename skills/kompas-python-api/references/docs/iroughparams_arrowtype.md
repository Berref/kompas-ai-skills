Примечание:

Для обозначения шероховатости используются следующие типы стрелок:

•стрелка (внутри/снаружи);

•засечка;

•засечка c наклоном влево;

•вспомогательная точка;

•без стрелки.

Подразделы:

(отсутствуют)
