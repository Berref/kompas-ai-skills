Интерфейс позволяет контролировать редактирование графического документа.

В Automation источник событий для подписки [Document2DNotify](document2dnotify.html) можно получить при помощи метода [ksDocument2D::GetDocument2DNotify](ksdocument2d_getdocument2dnotify.html).

В COM источником для подписки является графический документ.
