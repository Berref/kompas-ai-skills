Аналог данных параметров при использовании Automation - интерфейс [ksPhantom](ksphantom.html).

unsigned short | phType | тип фантома  
---|---|---  
struct Type1 | type1 | параметры сдвига группы (phType=1)  
struct Type2 | type2 | параметры фантома-отрезка (phType=2)  
struct Type3 | type3 | параметры фантома-прямоугольника (phType=3)  
struct Type3 | type4 | параметры фантома-отрезка с заданным углом (phType=4)  
struct Type5 | type5 | параметры фантома-половины прямоугольника (phType=5)  
struct Type6 | type6 | параметры пользовательского фантома (phType=6)  
struct Type2 | type7 | параметры фантома-окружности (phType=7)

Примечания:

1\. Какая из структур параметров фантома - Type1, Type2, Type3, Type5 или Type6 используется, зависит от значения параметра phType.

2\. Фантом-отрезок и фантом-окружность используют одну структуру параметров - Type2.

3\. Фантом-прямоугольник и фантом-отрезок с заданным углом используют одну структуру параметров - Type3.
