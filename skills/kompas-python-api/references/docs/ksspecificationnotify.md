ISpecificationNotify | \- интерфейс COM  
  
Позволяют контролировать редактирование описания спецификации.

В Automation источником событий для подписки на данный интерфейс является объект [ksSpecification](ksspecification.html).

В COM источником для подписки является является документ (графический документ, документ-модель, спецификация).
