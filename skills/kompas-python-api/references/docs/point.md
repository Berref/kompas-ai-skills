Аналог данной функции при использовании Automation - метод [ksDocument2D::ksPoint](ksdocument2d_kspoint.html)

Синтаксис:

reference Point (double x, double y,

unsigned int style);

Входные параметры:

x, y | \- координаты точки,  
---|---  
style | \- [стиль отрисовки точек](pstyles.html).  
  
Возвращаемое значение:

указатель на графический объект Точка | \- в случае удачного завершения,  
---|---  
0 | \- в случае неудачи.  
  
Примечание:

Объект создается в текущем слое текущего вида.
