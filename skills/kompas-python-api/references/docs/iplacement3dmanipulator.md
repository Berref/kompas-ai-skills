Примечание

Манипулятор позволяет указать положение при работе в 3D.

Интерфейс можно получить, добавив манипулятор через коллекцию манипуляторов [IManipulators::Add](imanipulators_add.html).

Интерфейс является дополнительным для [IBaseManipulator](ibasemanipulator.html).

Версия: KOMPAS v19
