Примечание:

1\. Данный интерфейс можно получить через интерфейс коллекции элементов управления панели свойств [IPropertyControls](ipropertycontrols.html).

2\. При нажатии на кнопку элемента управления вызывается событие [ksPropertyManagerNotify::ControlCommand](kspropertymanagernotify_controlcommand.html).

3\. При изменении значения элемента управления вызывается событие [ksIPropertyManagerNotify::ChangeControlValue](kspropertymanagernotify_changecontrolvalue.html).
