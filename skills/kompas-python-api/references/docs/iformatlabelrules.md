Интерфейс Правила формирования отображаемых имен объектов в дереве документа.

Иерархия:

IDispatch

[IKompasAPIObject](ikompasapiobject.html)

[IFormatLabelRules](iformatlabelrules.html)

Описание:

1\. Интерфейс позволяет сформировать правила формирования отображаемых имен объектов в дереве документа.

2\. Интерфейс можно получить с помощью метода [IDocumentSettings1::FormatLabelRules](idocumentsettings1_formatlabelrules.html).

Версия: Компас v20
