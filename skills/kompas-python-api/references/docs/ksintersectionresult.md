ksIntersectionResult | \- интерфейс Automation  
---|---  
IIntersectionResult | \- интерфейс COM  
  
Примечание:

1\. Интерфейс используется при проверке наличия пересечения тел в сборке. См. функцию [ksBody::CheckIntersectionWithBody](ksbody_checkintersectionwithbody.html).

2\. Два тела в сборке могут иметь более одного пересечения. См. также [Типы пересечений](intersection_type.html)

3\. Данный интерфейс можно получить от интерфейсов трехмерного тела [ksBody](ksbody.html) или [IBody](ksbody.html).
