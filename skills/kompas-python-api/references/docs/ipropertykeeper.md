Интерфейс получения/редактирования значения свойств

Иерархия:

IDispatch

[IPropertyKeeper](ipropertykeeper.html)

Описание:

Позволяет получать и редактировать значения свойств объектов.

Примечание:

Дополнительный интерфейс. Данный интерфейс можно получить у [IPart7](ipart7.html), [IBody7](ibody7.html), [IEmbodiment](iembodiment.html), [IMacroObject](imacroobject.html), [IInsertionObject](iinsertionobject.html) или [IKompasDocument2D](ikompasdocument2d.html) посредством вызова метода [IUnknown::QueryInterface (const GUID far& iid, void** pif)](recomendation.html).
