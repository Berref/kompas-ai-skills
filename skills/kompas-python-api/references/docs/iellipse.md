Описание:

Интерфейс позволяет получить и задать свойства эллипса.

Примечание:

1\. Интерфейс можно получить, используя свойство коллекции эллипсов [IEllipses::Ellipse](iellipses_ellipse.html) или метод [IEllipses::Add](iellipses_add.html).

2\. После задания параметров эллипса требуется вызвать метод [IDrawingObject::Update](idrawingobject_update.html).
