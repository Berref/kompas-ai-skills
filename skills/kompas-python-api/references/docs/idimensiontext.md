Примечание:

Является дополнительным интерфейсом для 2D и 3D размеров (интерфейсы [IAngleDimension3D](iangledimension3d.html), [IAngleDimension](iangledimension.html), [IArcDimension](iarcdimension.html), [IBaseLineDimension3D](ibaselinedimension3d.html), [IBreakAngleDimension](ibreakangledimension.html), [IBreakLineDimension](ibreaklinedimension.html), [IBreakRadialDimension](ibreakradialdimension.html), [IDiametralDimension3D](idiametraldimension3d.html), [IDiametralDimension](idiametraldimension.html), [IHeightDimension](iheightdimension.html), [ILineDimension3D](ilinedimension3d.html), [ILineDimension](ilinedimension.html), [IRadialDimension3D](iradialdimension3d.html), [IRadialDimension](iradialdimension.html)). Позволяет сформировать нужный текст размерной надписи.
