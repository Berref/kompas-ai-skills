Интерфейс операции сшивки поверхностей.

Иерархия:

[IKompasAPIObject](ikompasapiobject.html)

[IModelObject](imodelobject.html)

[ISurfaceSewer](isurfacesewer.html)

Описание:

Интерфейс позволяет создавать и редактировать операцию сшивки поверхностей.

Примечание:

1\. Интерфейс можно получить у коллекции заплаток, используя свойство [ISurfaceSewers::SurfaceSewer](isurfacesewers_surfacesewer.html) или метод [ISurfaceSewers::Add](isurfacesewers_add.html).

2\. После задания параметров заплатки требуется вызвать метод [IModelObject::Update](imodelobject_update.html).
