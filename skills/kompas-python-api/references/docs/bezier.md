Аналог данной функции при использовании Automation - метод [ksDocument2D::ksBezier](ksdocument2d_ksbezier.html).

Синтаксис:

int Bezier (int closed, unsigned int style);

Входные параметры:

closed | \- признак замыкания сплайна: 0 - незамкнутый, 1 - замкнутый,  
---|---  
style | стиль линии.  
  
[Системные стили линий...](lstyles.html)

Возвращаемое значение:

1 | \- в случае успешного завершения,  
---|---  
0 | \- в случае неудачи.  
  
Примечание:

1\. Характерные точки кривой Безье задаются функциями [Point](point.html) (если не надо задавать производные в узлах) или [BezierPoint](bezierpoint.html) (при необходимости задания производных) до вызова [EndObj](endobj.html).

2\. Объект создается в текущем слое текущего вида.

3\. В качестве стиля линии можно задавать номер системного или пользовательского стиля линии.

4\. Функция EndObj возвращает указатель на созданный объект Кривая Безье.
