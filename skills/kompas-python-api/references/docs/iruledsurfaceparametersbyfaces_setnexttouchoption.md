Синтаксис Automation:

BOOL SetNextTouchOption( BOOL Forward );

Синтаксис COM:

HRESULT SetNextTouchOption( BOOL Forward, BOOL * Result );

Возвращаемое значение:

TRUE | \- в случае успешного завершения,  
---|---  
FALSE | \- в случае неудачи.  
  
Входные параметры

Forward | \- TRUE - установить следующий вариант,  
\- FALSE - установить предыдущий вариант.
