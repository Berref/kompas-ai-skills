Интерфейс параметров копирования объектов вдоль кривой.

Иерархия:

IDispatch

[IKompasAPIObject](ikompasapiobject.html)

[ICurveCopyObjectParam](icurvecopyobjectparam.html)

Описание:

Интерфейс позволяет задавать и получать параметры копирования объектов вдоль кривой.

Примечание:

Интерфейс является дополнительным для интерфейса [ICopyObjectParam](icopyobjectparam.html). Он может быть получен с помощью метода [IUnknown::QueryInterface](recomendation.html).
