---|---  
Object.DefaultValue = DefaultValue | Установить свойство ([* ](1.html))  
DefaultValue = Object.GetDefaultValue() | Получить свойство ([**](2.html))  
Object.SetDefaultValue( DefaultValue ) | Установить свойство ([**](2.html))

---|---  
Object.put_DefaultValue(DefaultValue) | Установить свойство  
  
Примечание
