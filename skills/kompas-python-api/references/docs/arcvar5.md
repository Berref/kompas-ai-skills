# По углу, точке и радиусу

---|---  
  
Требуется задать следующие параметры:

•координаты центра ([XC](iarc_xc.html); [YC](iarc_yc.html)),

•угол между осью X и направлением на первую [Angle1](iarc_angle1.html), или вторую [Angle2](iarc_angle2.html) точку,

•координаты начальной ([X1](iarc_x1.html); [Y1](iarc_y1.html)), если задан угол на точку 2 или конечной ([X2](iarc_x2.html); [Y2](iarc_y2.html)), если задан угол на точку 1 точек,

•радиус [Radius](iarc_radius.html),

•направление [Direction](iarc_direction.html).
