Синтаксис:

int LIB_FUNC ksSetApplyLibrarySpcStyle( int librarySpcStyle );

Входные параметры:

librarySpcStyle | 1 - использовать стиль СП из библиотеки, а не втянутый в документ.  
---|---  
  
Возвращаемое значение:

1 | \- в случае успешного завершения,  
---|---  
0 | \- в случае неудачи.
