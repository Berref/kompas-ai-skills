Для приложения в content-директории в подпапке Libs(data) создайте каталог Help. В него поместите подкаталог <App ID>_ru-RU, в котором должна располагаться веб-справка. Также в каталоге Help должен быть файл <App ID>.hh. При сборке бинарного контента в svn создастся <App ID>_ru-RU.zip и файл pages.db автоматически.
