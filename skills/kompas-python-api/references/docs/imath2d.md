Интерфейс 2D математики.

Иерархия:

IDispatch

[IKompasAPIObject](ikompasapiobject.html)

[IMath2D](imath2d.html)

Описание:

Интерфейс позволяет создавать математические кривые и осуществлять работу с точками.

Примечание:

Интерфейс можно получить у интерфейса приложения КОМПАС с помощью свойства [IApplication::Math2D](iapplication_math2d.html).
