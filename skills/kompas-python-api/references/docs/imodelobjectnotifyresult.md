Интерфейс результатов редактирования 3d объекта.

Иерархия:

IDispatch

[IModelObjectNotifyResult](imodelobjectnotifyresult.html)

Описание:

Позволяет контролировать редактирование объектов документа-модели. Источником событий для подписки является указатель на интерфейс [IModelObject](imodelobject.html).

Примечание:

Получить интерфейс можно с помощью метода [IUnknown::QueryInterface](recomendation.html) у интерфейса компонента [IPart7](ipart7.html).
