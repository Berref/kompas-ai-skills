Синтаксис:

reference LinBreakDimension (LBreakDimParam *linPar);

Выходной параметр:

linPar | \- указатель на структуру параметров линейного размера с обрывом [LBreakDimParam](structlbreakdimparam.html).  
---|---  
  
Возвращаемое значение:

указатель на линейный размер с обрывом | \- в случае удачного завершения,  
---|---  
0 | \- в случае неудачи.
