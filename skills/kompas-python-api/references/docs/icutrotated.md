Иерархия:

IDispatch

[IKompasAPIObject](ikompasapiobject.html)

[IModelObject](imodelobject.html)

[IRotated](irotated.html)

[ICutRotated](icutrotated.html)

Интерфейс позволяет создавать и редактировать операции вырезания вращением. Имеет дополнительный интерфейс [IThinParameters](ithinparameters.html), который можно получить с помощью метода [IUnknown::QueryInterface](recomendation.html).

Примечание:

Интерфейс можно получить с помощью свойства [IRotateds::Rotated](irotateds_rotated.html) и метода [IRotateds::Add](irotateds_add.html) с типом o3d_cutRotated.
