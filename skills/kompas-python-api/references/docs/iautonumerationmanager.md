Интерфейс Менеджер автонумерации.

Иерархия:

IDispatch

[IAutoNumerationManager](iautonumerationmanager.html)

Примечание:

1\. Интерфейс является дополнительным к интерфейсу 2D документа [IKompasDocument2D](ikompasdocument2d.html).

2\. В 2D документе создается три системные группы нумерации:

•#Автосортировка.

•#Нумерация обозначений изменений.

•#Нумерация таблиц.

Дополнительно могут быть созданы пользовательские группы нумерации.

Версия: Компас v20
