Нутация (от лат. nutatio — колебание), происходящее одновременно с [прецессией](prezession.html) движение твёрдого тела, при котором изменяется угол между осью собственного вращения тела и осью, вокруг которой происходит прецессия; этот угол называется углом нутации.
