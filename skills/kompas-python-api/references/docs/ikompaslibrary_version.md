Тип данных: long

Синтаксис:

HRESULT Version( long * Result );

Примечание:

Свойство позволяет получить версию интерфейса, реализованного в библиотеке.

При доработках интерфейса в Компас версия интерфейса будет увеличиваться.

Новые методы для библиотек со старой версией вызываться не будут.
