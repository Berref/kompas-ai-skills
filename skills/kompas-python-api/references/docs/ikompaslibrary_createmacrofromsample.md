Синтаксис:

HRESULT CreateMacroFromSample( long MacroReference, VARIANT_BOOL * Result );

Входные параметры:

MacroReference | \- идентификатор (reference) библиотечного макрообъекта  
---|---  
  
Возвращаемое значение:

Не используется

Примечание:

1\. При запуске команды Объект по образцу одновременно с другими элементами КОМПАС-График будут подсвечиваться и библиотечные макрообъекты, если создавшая их библиотека подключена и поддерживает данную функцию. Подсвеченные макрообъекты могут быть выбраны в качестве образца, после чего управление передается в блок обработки библиотеки.

2\. В блок обработки команды Объект по образцу передается идентификатор (указатель reference) выбранного макрообъекта. По этому указателю на макрообъект можно получить параметры макрообъекта, обработать их и запустить соответствующую команду библиотеки.

3\. Функция вызывается, если приложение подтвердило что поддерживает работу данного метода (см. [IKompasLibrary::IsFunctionEnable](ikompaslibrary_isfunctionenable.html)).
