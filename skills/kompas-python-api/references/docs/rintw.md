# RIntW - Определить в отношении поле типа short int (Unicode)

Аналог данной функции при использовании Automation - метод [ksDataBaseObject::ksRInt](ksdatabaseobject_ksrint.html).

Синтаксис:

int LODBC_FUNC RIntW (LPWSTR name);

Входной параметр:

name | \- имя поля.  
---|---  
  
Возвращаемое значение:

1 | \- в случае успешного завершения,  
---|---  
0 | \- в случае неудачи.  
  
Примечание:

1\. Параметр name действителен только при работе с текстовыми базами данных.

2\. При использовании ANSI следует использовать функцию [RInt](rint.html).
