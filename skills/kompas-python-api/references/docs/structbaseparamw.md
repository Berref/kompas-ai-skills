# BaseParamW - Структура параметров обозначения базы (Unicode)

[Структуры параметров и константы](3d_define.html) > [Структуры параметров объектов оформления чертежа ](bk1738515.html) |  Scroll [ [ [ ](structbrandleaderparam.html "К следующему разделу")](bk1738515.html "На уровень выше")](structbaseparam.html "К предыдущему разделу")  
---|---  
  
Аналог данных параметров при использовании Automation - интерфейс [ksBaseParam](ksbaseparam.html).

unsigned short | style | стиль текста (0 - стиль по умолчанию),  
---|---|---  
double | x1, y1 | координаты базовой точки (начало "опоры"),  
double | x2, y2 | координаты конечной точки "опоры",  
unsigned char | type | способ задания надписи в обозначении базы (0 - текст в виде строки, 1 - динамический массив компонентов текста),  
wchar_t | str [50] | текст в обозначении базы,  
reference | pTextItem | динамический массив компонентов текста TEXT_ITEM_ARR.  
  
Примечание:

1\. Какой из параметров - str или pTextItem используется, определяется значением параметра type.

2\. При использовании ANSI следует использовать структуру параметров [BaseParam](structbaseparam.html).
