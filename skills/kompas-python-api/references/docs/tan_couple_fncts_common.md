Функции данного раздела обеспечивают вычисление касаний и сопряжений геометрических объектов.

Подразделы:

[CouplingLineLine - Получить параметры окружностей, касательных к двум прямым ](couplinglineline.html)

[ksCouplingCircleCircle - Получить параметры сопрягающих окружностей определенного радиуса и точки сопряжения для двух окружностей ](kscouplingcirclecircle.html)

[ksCouplingLineCircle - Получить параметры сопрягающих окружностей определенного радиуса и точки касания при сопряжении окружности и прямой ](kscouplinglinecircle.html)

[ksCouplingLineLine - Получить параметры сопряжения двух прямых ](kscouplinglineline.html)

[ksTanLinePointCurve - Получить точки касания кривой и прямой, проведенной из заданной точки ](kstanlinepointcurve.html)

[TanCircleCircle - Получить координаты точек касания прямых к двум окружностям ](tancirclecircle.html)

[TanLineAngCircle - Получить точки касания окружности и прямой, проходящей под заданным углом ](tanlineangcircle.html)

[TanLinePointCircle - Получить точки касания окружности и прямой, проходящей через заданную точку ](tanlinepointcircle.html)
