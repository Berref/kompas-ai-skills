# Использование библиотек типов интерфейсов Системы КОМПАС-3D

---|---  
  
При использовании библиотек типов *.tlb КОМПАС-3D требуется их регистрация на компьютере разработчика и, в некоторых случаях, на компьютере пользователя. Для регистрации библиотек типов Системы КОМПАС скопируйте библиотеки типов в папку \Bin системы КОМПАС-3D (если их там нет) и запустите КОМПАС-3D с ключом /register.

Если у вас уже были зарегистрированы библиотеки типов от предыдущей версии КОМПАС-3D, то перед регистрацией новых библиотек потребуется отмена регистрации прежних. Для этого запустите предыдущую версию КОМПАС-3D с ключом /unregister. Данная операция требуется как на компьютере разработчика, так и на компьютере пользователя.
