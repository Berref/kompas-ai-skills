# ksSpecificationOnSheet - Включить или выключить показ спецификации на листе чертежа

Аналог данной функции при использовании Automation - метод [ksDocument2D::ksSpecificationOnSheet](ksdocument2d_ksspecificationonsheet.html).

Синтаксис:

int ksSpecificationOnSheet (unsigned char onSheet);

Входной параметр:

onSheet | \- признак размещения спецификации на листе 1 - включено, 0 - выключено.  
---|---  
  
Возвращаемое значение:

1 | \- в случае успешного завершения,  
---|---  
0 | \- в случае неудачи.

(отсутствуют)
