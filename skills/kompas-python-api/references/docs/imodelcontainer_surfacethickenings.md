Тип данных: указатель на интерфейс коллекции операций придания толщины [ISurfaceThickenings](isurfacethickenings.html).

Синтаксис Automation:

SurfaceThickenings = Object.SurfaceThickenings | Получить свойство ([* ](1.html))  
---|---  
SurfaceThickenings = Object.GetSurfaceThickenings() | Получить свойство ([**](2.html))  
  
Синтаксис COM:

Object.get_SurfaceThickenings( &SurfaceThickenings ) | Получить свойство  
---|---  
  
Свойство позволяет получить коллекцию всех операций придания толщины, входящих в состав данного объекта.

Примечание:

Свойство доступно только для чтения.
