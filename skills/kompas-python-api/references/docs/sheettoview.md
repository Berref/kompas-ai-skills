Аналог данной функции при использовании Automation - метод [ksDocument2D::ksSheetToView](ksdocument2d_kssheettoview.html).

Синтаксис:

int (double x, double y, double * outX, double * outY);

Входные параметры:

x, y | \- координаты точки в системе координат листа.  
---|---  
  
Выходные параметры:

outX, outY | \- координаты точки в системе координат вида.  
---|---  
  
Возвращаемое значение:

1 | \- в случае успешного завершения,  
---|---  
0 | \- в случае неудачи.
