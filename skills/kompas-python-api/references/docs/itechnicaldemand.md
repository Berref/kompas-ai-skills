Описание:

Интерфейс позволяет задавать и получать параметры технических требований.

Примечание:

Интерфейс можно получить у интерфейса чертежа с помощью свойства [IDrawingDocument::TechnicalDemand](idrawingdocument_technicaldemand.html).
