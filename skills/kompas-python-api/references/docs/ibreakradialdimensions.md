Интерфейс коллекции радиальных размеров c изломом.

Иерархия:

[IKompasAPIObject](ikompasapiobject.html)

[IKompasCollection](ikompascollection.html)

[IDrawingObjects](idrawingobjects.html)

[IBreakRadialDimensions](ibreakradialdimensions.html)

Описание:

Интерфейс позволяет получать и создавать радиальные размеры с изломом.

Примечание:

Данный интерфейс можно получить у контейнера условных обозначений, используя свойство [ISymbols2DContainer::BreakRadialDimensions](isymbols2dcontainer_breakradialdimensions.html).
