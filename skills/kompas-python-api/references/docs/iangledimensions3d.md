Интерфейс коллекции угловых размеров 3D.

Иерархия:

[IKompasAPIObject](ikompasapiobject.html)

[IKompasCollection](ikompascollection.html)

[IModelObject](imodelobject.html)

[IAngleDimensions3D](iangledimensions3d.html)

Описание:

Интерфейс позволяет получить и создавать угловые размеры в 3D документе.

Коллекция содержит угловые и угловые с обрывом размеры.

Данный интерфейс можно получить у контейнера условных обозначений, используя свойство [ISymbols3DContainer::AngleDimensions3D](isymbols3dcontainer_angledimensions3d.html).
