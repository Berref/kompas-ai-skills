Интерфейс формата листа.

Иерархия:

[IKompasAPIObject](ikompasapiobject.html)

[ISheetFormat](isheetformat.html)

Примечание:

1\. Данный интерфейс позволяет получить и изменить текущий формат листа для документа.

2\. Данный интерфейс может быть получен следующими способами:

•от интерфейса стиля спецификации [ISpecificationStyle](ispecificationstyle.html) с помощью свойства [ISpecificationStyle::Format](ispecificationstyle_format.html),

•от интерфейса параметров листа оформления [ILayoutSheet](ilayoutsheet.html) с помощью свойства [ILayoutSheet::Format](ilayoutsheet_format.html).
