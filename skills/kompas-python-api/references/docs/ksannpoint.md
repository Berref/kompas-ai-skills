# ksAnnPoint - Создать объект "точка" c аннотационной точкой привязки

[API экспортных функций](export_function.html) > [Функции работы с графическим документом ](cm1726661.html) > [Создание графических объектов ](cm1732355.html) > [Аннотационные объекты ](ann_objects_fncts_common.html) |  Scroll [ [ [ ](ksannpolyline.html "К следующему разделу")](ann_objects_fncts_common.html "На уровень выше")](ksannparellipsearc.html "К предыдущему разделу")  
---|---  
  
Аналог данной функции при использовании Automation - метод [ksDocument2D::ksAnnPolyline](ksdocument2d_ksannpolyline.html).

Синтаксис:

reference LIB_FUNC ksAnnPoint( double x,

double y,

unsigned short style );

Входные параметры:

x, y | \- координаты точки,  
---|---  
style | \- стиль отрисовки точки: 0 - точка, 1 - крестик, 2 - х-точка, 3 - квадрат, 4 - треугольник, 5 - окружность, 6 - звезда, 7 - перечеркнутый квадрат, 8 - утолщенный плюс.  
  
Возвращаемое значение:

указатель на точку | \- в случае удачного завершения,  
---|---  
0 | \- в случае неудачи.  
  
Примечание:

1\. Аннотационные объекты можно создавать только в составе макро. Допускается создание аннотационных объектов во временной группе для последующего добавления в макро.

2\. При разрушении макро-аннотационные объекты превращаются в геометрические.

3\. Координаты точки привязки аннотационные не зависят от масштаба вида.
