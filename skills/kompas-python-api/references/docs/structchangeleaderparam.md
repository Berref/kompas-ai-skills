# ChangeLeaderParam - Структура параметров линии-выноски для обозначения изменения

[Структуры параметров и константы](3d_define.html) > [Структуры параметров объектов оформления чертежа ](bk1738515.html) |  Scroll [ [ [ ](structcutlineparam.html "К следующему разделу")](bk1738515.html "На уровень выше")](structbrandleaderparam.html "К предыдущему разделу")  
---|---  
  
Аналог данных параметров при использовании Automation - интерфейс [ksChangeLeaderParam](kschangeleaderparam.html).

double | x | координаты базовой точки (начало пeрвой полки),  
---|---|---  
double | y  
unsigned short | style | стиль текста,  
unsigned char | signType | тип значка,  
double | signHeight | высота значка,  
double | leaderLength | длина выноски (< 0 - на всю длину),  
reference | pText | если style = INDICATIN_TEXT_LINE_ARR, то pText = TEXT_LINE_ARR - динамический массив строк текста, если style = 0, то pText = CHAR_STR_ARR или CHAR_STR_ARR_W - динамический массив строк символов текста. Строки текстов лежат в следующей последовательности: \- текст над полкой, \- текста над ножкой, \- текст под ножкой,  
reference | pPolyline | POLYLINE_ARR - массив неопределенной длины ответвлений линии выноски. В общем случае одно ответвление - это полилиния. Первый узел - базовая точка (ее в массив помещать не нужно - общая для всех ответвлений). Остальные узлы - изломы могут отсутствовать), последний узел - конец ответвления (указывает на объект).
