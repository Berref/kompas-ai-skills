Аналог данной функции при использовании Automation - метод [ksDocument2D::ksParagraph](ksdocument2d_ksparagraph.html).

Синтаксис:

int Paragraph (ParagraphParam *par);

Выходной параметр:

par | \- указатель на структуру параметров параграфа [ParagraphParam](structparagraphparam.html).  
---|---  
  
Возвращаемое значение:

1 | \- в случае успешного завершения,  
---|---  
0 | \- в случае неудачи.  
  
Описание:

1\. Параграфом называется автоматически форматируемый блок текста (левосторонний, правосторонний, центрированный, по двум сторонам).

2\. При работе в текстовом процессоре он завершается символом <ENTER>. Описание параграфа заканчивается функцией [EndObj](endobj.html), возвращающей указатель на созданный объект.
