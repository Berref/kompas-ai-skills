Источник событий объектов графического документа.

В Automation источник событий для графического документа Object2DNotify можно получить при помощи метода [ksDocument2D::GetObject2DNotify](ksdocument2d_getobject2dnotify.html).

В СOM контейнером для подписки на данный интерфейс является указатель на графический документ или документ-модель.

[Интерфейс событий объектов графического документа...](ksobject2dnotify.html)

Примечание:

Интерфейс позволяет следить и управлять редактированием объектов графического документа.
