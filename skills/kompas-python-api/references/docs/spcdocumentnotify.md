Источник событий для документа-спецификации.

Указатель на источник событий SpcDocumentNotify можно получить при помощи метода [ksSpcDocument::GetSpcDocumentNotify](ksspcdocument_getspcdocumentnotify.html).

В COM источником для подписки является документ-спецификация.
