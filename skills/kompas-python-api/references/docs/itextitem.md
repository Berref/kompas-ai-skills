Интерфейс компоненты строки текста.

Иерархия:

[IKompasAPIObject](ikompasapiobject.html)

[ITextItem](itextitem.html)

Описание:

Интерфейс позволяет получить и отредактировать компонент строки текста. Компонент строки - это часть строки, отличающаяся типом [ksTextItemEnum](kstextitemenum.html) и параметрами шрифта.

Интерфейс имеет дополнительные интерфейсы [ITextFont](itextfont.html) и [IHypertextReferenceParam](ihypertextreferenceparam.html).

Примечание:

Данный интерфейс можно получить через интерфейс ITextLine, используя свойство [ITextLine::TextItem](itextline_textitem.html).
