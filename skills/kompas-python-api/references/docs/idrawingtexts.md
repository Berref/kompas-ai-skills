Интерфейс коллекции текстов на чертеже.

Иерархия:

[IKompasAPIObject](ikompasapiobject.html)

[IKompasCollection](ikompascollection.html)

[IDrawingObjects](idrawingobjects.html)

[IDrawingTexts](idrawingtexts.html)

Описание:

Интерфейс позволяет получить доступ к текстам на чертеже для указанного вида, а также создавать новые тексты.

Примечание:

Данный интерфейс можно получить у интерфейса IDrawingContainer, используя свойство [IDrawingContainer::DrawingTexts](idrawingcontainer_drawingtexts.html).
