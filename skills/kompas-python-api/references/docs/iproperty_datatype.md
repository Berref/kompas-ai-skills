Синтаксис Automation:

DataType = Object.DataType | Получить свойство ([* ](1.html))  
---|---  
Object.DataType = DataType | Установить свойство ([* ](1.html))  
DataType = Object.GetDataType() | Получить свойство ([**](2.html))  
Object.SetDataType( DataType ) | Установить свойство ([**](2.html))  
  
Синтаксис COM:

Object.get_DataType( &DataType ) | Получить свойство  
---|---  
Object.put_DataType( DataType ) | Установить свойство  
  
Свойство позволяет устанавливать и получать тип свойства.

Примечание:

Свойство можно установить только для вновь создаваемых свойств.
