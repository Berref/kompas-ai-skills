Тип данных:long.

Значения свойства:

0 | \- автоматическое размещение текста,  
---|---  
> 0 | \- значение расстояния от выносной линии до текста в направлении от первой точки ко второй.  
  
Синтаксис Automation:

textPos = iBreakDimDrawing.textPos | Получить свойство ([* ](1.html))  
---|---  
iBreakDimDrawing.textPos = textPos | Установить свойство ([* ](1.html))  
textPos = iBreakDimDrawing.GetTextPos() | Получить свойство ([**](2.html))  
iBreakDimDrawing.SetTextPos( textPos ) | Установить свойство ([**](2.html))  
  
Примечание:

Свойство является аннотационным (не зависит от масштаба, показывает расстояние "на бумаге").
