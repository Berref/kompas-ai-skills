Описание:

Интерфейс позволяет получать и создавать линейные размеры с обрывом.

Примечание:

Данный интерфейс можно получить у контейнера условных обозначений, используя свойство [ISymbols2DContainer::BreakLineDimensions](isymbols2dcontainer_breaklinedimensions.html).
