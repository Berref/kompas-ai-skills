[IKompasCollection](ikompascollection.html)

[IModelObject](imodelobject.html)

[ILineDimensions3D](ilinedimensions3d.html)

Описание:

Интерфейс позволяет получить и создавать линейные размеры (от отрезка до точки и на плоскости) в 3D документе.

Коллекция содержит линейные размеры (от отрезка до точки и на плоскости).

Данный интерфейс можно получить у контейнера условных обозначений, используя свойство [ISymbols3DContainer::LineDimensions3D](isymbols3dcontainer_linedimensions3d.html).
