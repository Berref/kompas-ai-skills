# ksSetZoomScale - Задать масштаб изображения по точке и коэффициенту масштабирования

Синтаксис:

int LIB_FUNC ksSetZoomScale ( double x, double y, double scale, int viewParam );

Входные параметры:

x, y | \- координаты (в СК вида) точки центра изменения масштаба,  
---|---  
scale | \- масштаб изображения.  
viewParam | \- TRUE - Координаты центра в СК текущего вида, \- FALSE - Координаты центра в СК листа.  
  
Возвращаемое значение:

TRUE | \- в случае успешного завершения,  
---|---  
FALSE | \- в случае неудачи.
