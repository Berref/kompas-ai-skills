# ksAnnPolyline - Создать аннотационную ломаную линию

[API экспортных функций](export_function.html) > [Функции работы с графическим документом ](cm1726661.html) > [Создание графических объектов ](cm1732355.html) > [Аннотационные объекты ](ann_objects_fncts_common.html) |  Scroll [ [ [ ](ksannpolylineex.html "К следующему разделу")](ann_objects_fncts_common.html "На уровень выше")](ksannpoint.html "К предыдущему разделу")  
---|---  
  
Аналог данной функции при использовании Automation - метод [ksDocument2D::ksAnnPolyline](ksdocument2d_ksannpolyline.html).

Синтаксис:

int ksAnnPolyline( unsigned short style,

unsigned char term1,

unsigned char term2 );

Входные параметры:

style | \- [стиль линии,](lstyles.html)  
---|---  
term1, term2 | \- [типы значков](marktypes.html) на концах ломаной.  
  
Возвращаемое значение:

указатель на аннотационную ломаную линию | \- в случае удачного завершения,  
---|---  
0 | \- в случае неудачи.  
  
Примечание:

1\. Аннотационные объекты можно создавать только в составе макро. ksAnnPolyline - составной объект. Объекты Point, вводимые между операторами ksAnnPolyline и EndObj, принадлежат аннотационной полилинии. Допускается создание аннотационных объектов во временной группе для последующего добавления в макро.

2\. При разрушении макро-аннотационные объекты превращаются в геометрические.
