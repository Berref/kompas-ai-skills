Аналог данной функции при использовании Automation - метод [ksDataBaseObject::ksDeleteDB](ksdatabaseobject_ksdeletedb.html).

Синтаксис:

int DeleteDB(reference bd);

Входной параметр:

bd | \- указатель на объект БД.  
---|---  
  
Возвращаемое значение:

1 | \- в случае успешного завершения,  
---|---  
0 | \- в случае неудачи.  
  
Примечание:

Функция позволяет закрыть БД. После ее выполнения происходит автоматическое отсоединение базы данных и удаление всех созданных ранее запросов.
