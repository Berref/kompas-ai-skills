# ksAnnCircle - Создать объект "Аннотационная окружность"

[API экспортных функций](export_function.html) > [Функции работы с графическим документом ](cm1726661.html) > [Создание графических объектов ](cm1732355.html) > [Аннотационные объекты ](ann_objects_fncts_common.html) |  Scroll [ [ [ ](ksannellipse.html "К следующему разделу")](ann_objects_fncts_common.html "На уровень выше")](annlineseg.html "К предыдущему разделу")  
---|---  
  
Аналог данной функции при использовании Automation - метод [ksDocument2D::ksAnnCircle](ksdocument2d_ksanncircle.html).

Синтаксис:

reference ksAnnCircle ( double xc,

double yc,

double rad,

unsigned short style );

Входные параметры:

xc, yc | \- координаты центра окружности,  
---|---  
rad | \- радиус окружности,  
style | \- [стиль линии](lstyles.html).  
  
Возвращаемое значение:

указатель на аннотационную окружность | \- в случае удачного завершения,  
---|---  
0 | \- в случае неудачи.  
  
Примечание:

1\. Аннотационные объекты можно создавать только в составе макро. Допускается создание аннотационных объектов во временной группе для последующего добавления в макро.

2\. При разрушении макро аннотационные объекты превращаются в геометрические.
