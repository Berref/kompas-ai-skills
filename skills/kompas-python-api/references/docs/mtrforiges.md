Синтаксис:

int MtrForIGES (double rotateMtr[2][2],

double moveArr[2]);

Входные параметры:

rotateMtr | \- матрица поворота,  
---|---  
moveArr | \- вектор сдвига.  
  
Возвращаемое значение:

1 | \- в случае успешного завершения,  
---|---  
0 | \- в случае неудачи.  
  
Примечание:

Все объекты вида, вводимые между операторами MtrForIGES и [DeleteMtr](deletemtr.html), подвергаются трансформации по суммарной матрице.
