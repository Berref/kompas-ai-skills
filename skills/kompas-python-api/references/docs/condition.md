Аналог данной функции при использовании Automation - метод [ksDataBaseObject::ksCondition](ksdatabaseobject_kscondition.html).

Синтаксис:

int Condition (reference bd, reference rel, char * str);

Входные параметры:

bd | \- указатель на объект БД,  
---|---  
rel | \- указатель на отношение,  
str | \- запрос.  
  
Возвращаемое значение:

1 | \- в случае успешного завершения,  
---|---  
0 | \- в случае неудачи.  
  
Примечание:

1\. При работе с базой данных через ODBC-интерфейс происходит переопределение составляющей SQL-запроса, начинающейся с ключевого слова WHERE. Состав обрабатываемых полей записи, определенный в отношении, не изменяется. При работе с текстовыми файлами использование функции [Condition](condition.html) является единственной возможностью определения условия запроса, так как в функции [DoStatement](dostatement.html) определяется только список обрабатываемых полей записи. Следует отметить, что при работе с текстовыми базами данных не обрабатывается вложенность условий (например, "where d > 10 and d < 14").

2\. Действительно для запроса Select....

3\. При использовании Unicode следует использовать функцию [ConditionW](conditionw.html).
