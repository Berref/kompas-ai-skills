Аналог данной функции при использовании Automation - метод [ksDocument2D::ksSetObjectStyle](ksdocument2d_kssetobjectstyle.html).

Синтаксис:

int ksSetObjectStyle( reference obj, unsigned int style );

Входные параметры:

obj | \- указатель reference объекта 2D,  
---|---  
style | \- номер стиля.  
  
Примечание:

Метод позволяет установить стиль для кривых и эквидистанты.
