Описание:

Интерфейс позволяет получать и создавать радиальные размеры.

Примечание:

Данный интерфейс можно получить у контейнера условных обозначений, используя свойство [ISymbols2DContainer::RadialDimensions](isymbols2dcontainer_radialdimensions.html).
