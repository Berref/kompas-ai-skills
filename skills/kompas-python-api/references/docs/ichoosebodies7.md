Интерфейс области применения для тел документа в операции.

Иерархия:

IDispatch

[IChooseBodies7](ichoosebodies7.html)

Описание:

Позволяет получить интерфейс области применения для тел документа в операции.

Примечание:

Данный интерфейс можно получить у операции выдавливание [IExtrusion](iextrusion.html) и интерфейса твердого тела [IBody7](ibody7.html) посредством вызова метода [IUnknown::QueryInterface (const GUID far& iid, void** pif)](recomendation.html);
