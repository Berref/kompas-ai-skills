Синтаксис COM:

HRESULT RemoveFolder ([in] BSTR PathFolder);

Входные параметры:

PathFolder | \- путь в Менеджере библиотек к папке. Если папка является вложенной, т. е. добавляется в другую папку, имена папок внутри пути отделяются символом "|".
