Синтаксис Automation:

LPDISPATCH GetPart (long type);

Синтаксис COM:

LPPART GetPart(int type);

Входной параметр:

type | \- тип компонента из перечисления [Типы компонентов](part_type.html).  
---|---  
  
Возвращаемое значение:

| \- указатель на интерфейс компонента [ksPart](kspart.html) или [IPart](kspart.html).  
---|---  
  
Примечание:

Тип задается для нового, редактируемого или главного компонента либо тип равен номеру компонента в документе.

Функция используется, чтобы получить доступ к компоненту документа.

Деталь или сборка являются компонентами. Сборка, в свою очередь, состоит из компонентов - деталей и подсборок.
