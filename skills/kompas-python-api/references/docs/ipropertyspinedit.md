Примечание:

1\. Данный интерфейс можно получить через коллекцию элементов управления Панели свойств [IPropertyControls](ipropertycontrols.html).

2\. При нажатии на кнопку счетчика вызывается событие [ksPropertyManagerNotify::ControlCommand](kspropertymanagernotify_controlcommand.html).

3\. При изменении значения параметра вызывается событие [ksPropertyManagerNotify::ChangeControlValue](kspropertymanagernotify_changecontrolvalue.html).
