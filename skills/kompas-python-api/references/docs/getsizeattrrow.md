Синтаксис:

int GetSizeAttrRow (reference pAttr);

Входной параметр:

pAttr | \- указатель на атрибут.  
---|---  
  
Возвращаемое значение:

длина строки атрибута | \- в случае удачного завершения,  
---|---  
0 | \- в случае неудачи.  
  
Примечание:

Функция устарела, рекомендуется вместо нее использовать функцию [ksGetSizeAttrRow](ksgetsizeattrrow.html).
