[IScaling3D](iscaling3d.html)

Интерфейс позволяет изменять размеры тела или поверхности в трех направлениях согласно заданному коэффициенту.

Интерфейс можно получить у коллекции операций масштабирования с помощью свойства [IScalings3D::Scaling3D](iscalings3d_scaling3d.html) и метода [IScalings3D::Add](iscalings3d_add.html).
