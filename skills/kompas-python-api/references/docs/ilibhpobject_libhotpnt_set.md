Синтаксис:

BOOL LibHotPnt_Set(HotPointDescription* point, int index );

Входные параметры:

index | \- номер характерной точки,  
---|---  
point | \- структура параметров характерной точки [HotPointDescription](structhotpointdescription.html).  
  
Возвращаемое значение:

TRUE | \- в случае удачного завершения.  
---|---  
  
Описание:

При перетаскивании характерной точки библиотечного элемента 2D c нажатой левой кнопкой мыши генерируется событие.

Этот метод позволяет отработать событие изменения положения характерной точки. Библиотека может изменить отображение библиотечного элемента или выполнить другие действия, связанные с этим событием.

Примечания:

1\. Актуальны только координаты (x, y), остальные поля должны игнорироваться.

2\. Значения координат приходят в собственной системе координат объекта.
