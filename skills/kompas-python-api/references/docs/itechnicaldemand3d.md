Описание:

Интерфейс позволяет задавать и получать параметры технических требований в 3D.

Примечание:

Интерфейс можно получить у интерфейса документа 3D с помощью свойства [IKompasDocument3D::TechnicalDemand3D](ikompasdocument3d_technicaldemand3d.html)
