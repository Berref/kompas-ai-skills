Интерфейс информации о текущей привязке.

Примечание.

Интерфейс позволяет получить информацию о привязке к объектам документа, сетке документа и о других типах привязки в процессах [CursorEx](cursorex.html), [PlacementEx](placementex.html).

Типы возможных привязок см. в перечислении [ksSnapTypeEnum](kssnaptypeenum.html).

Получить указатель на интерфейс можно с помощью функции [ksGetSnapInfo](ksgetsnapinfo.html).
