Object.get_Text( &Text ) | Получить свойство  
---|---  
  
Примечание.

1\. Свойство доступно только для чтения.

2\. Свойство позволяет получить указатель на интерфейс текста [IText](itext.html) для редактирования текста 3D базы. Указатель на интерфейс [IText](itext.html) вернётся только в случае отключенной опции "[Автосортировка](ibase3d_autosorted.html)". Если автосортировка текста включена, свойство вернёт NULL.
