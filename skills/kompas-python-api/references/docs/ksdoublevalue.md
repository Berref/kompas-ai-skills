Интерфейс для типа double.

Примечания:

1\. Данный интерфейс используется в качестве параметров узла NURBS и в динамическом массиве [ksDynamicArray](ksdynamicarray.html) типа DOUBLE_ARR.

2\. Указатель на интерфейс можно получить при помощи метода [KompasObject::GetParamStruct](kompasobject_getparamstruct.html).
