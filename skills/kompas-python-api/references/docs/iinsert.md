Интерфейс элемента (фрагмента или модели) библиотеки элементов.

Иерархия:

[IKompasAPIObject](ikompasapiobject.html)

[IInsert](iinsert.html)

Описание:

Позволяет получить доступ к документу-вставке в библиотеку элементов (фрагментов или моделей).

Примечание:

Данный интерфейс можно получить у интерфейса [IInserts](iinserts.html) с помощью свойства [IInserts::Item](iinserts_item.html) или метода [IInserts::Add](iinserts_add.html).
