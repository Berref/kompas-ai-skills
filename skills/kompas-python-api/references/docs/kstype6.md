Интерфейс параметров пользовательского фантома.

Аналог данных параметров при использовании API экспортных функций - [Type6](structtype6.html).

Примечание:

Этот интерфейс, в отличие от[ ksType1](kstype1.html), не устанавливает параметры поворота и масштабирования группы. Сдвиг группы должен осуществлять сам пользователь.

Указатель на интерфейс можно получить при помощи метода [ksPhantom::GetPhantomParam](ksphantom_getphantomparam.html).

Смотрите также: [ksPhantom](ksphantom.html)
