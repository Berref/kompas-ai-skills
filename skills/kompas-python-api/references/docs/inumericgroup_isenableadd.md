Синтаксис Automation:

BOOL IsEnableAdd( LPDISPATCH Object );

Синтаксис COM:

HRESULT IsEnableAdd( IKompasAPIObject * Object, BOOL * Result );

Возвращаемое значение:

TRUE | \- объект можно добавить в группу,  
---|---  
FALSE | \- объект в группу добавить нельзя.  
  
Входные параметры:

Object | \- указатель на интерфейс объекта [IKompasAPIObject](ikompasapiobject.html),  
---|---  
  
Примечание

1\. Возможно объект уже есть в группе.

2\. Не для всех типов объектов есть поддержка нумерации.

•В системных группах есть фильтр по типу объектов.

•Для группы #Автосортировка разрешено добавление объектов:

•Стрелка взгляда.

•Выносной элемент.

•Линия разреза\сечения.

•Обозначение базы.

•Линия-выноска.

•Размеры.

•В настройках документа есть управление автоматическим добавлением данных объектов в группу и задана последовательность сортировки.

•В группу #Нумерация обозначений изменений разрешено добавление:

•Обозначение изменения.

•В группу #Нумерация таблиц разрешено добавление:

•Таблиц и ассоциативных таблиц отчетов.

•Для пользовательских групп доступно добавление любых из выше перечисленных объектов. Другие объекты в группу добавить нельзя.
