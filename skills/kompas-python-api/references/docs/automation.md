# Автоматизация (Automation)

» Нет разделов более высокого уровня « |  Scroll  
---|---  
  
Технология Automation реализована в API системы КОМПАС через интерфейсы IDispatch.

С использованием интерфейсов такого типа можно получить доступ к системе как для работы с графическими документами, так и с трехмерными моделями. При этом может быть реализован весь функционал систем КОМПАС-ГРАФИК и КОМПАС-3D.

Dispath-интерфейсы могут быть использованы при программировании в большинстве современных сред: Visual Basic, Visual C++, C+Builder, Delphi.
