Интерфейс позволяет получать и создавать операции соединения кривых.

Интерфейс можно получить в контейнере вспомогательной геометрии с помощью метода [IAuxiliaryGeomContainer::ConnectCurves](iauxiliarygeomcontainer_connectcurves.html).
