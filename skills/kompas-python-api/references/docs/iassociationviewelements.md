Интерфейс - Объекты и элементы для передачи в ассоциативный вид.

Иерархия:

IDispatch

[IAssociationViewElements](iassociationviewelements.html)

Описание:

Интерфейс позволяет задать, какие объекты и элементы надо передавать в ассоциативный вид.

Примечание:

Интерфейс является дополнительным к интерфейсу ассоциативного вида [IAssociationView](iassociationview.html).
