Описание:

Интерфейс позволяет получать и изменять общие свойства для строительных осей.

Примечание:

Получить интерфейс строительной оси можно, используя методы коллекции строительных осей [IBuildingAxes::BuildingAxis](ibuildingaxes_buildingaxis.html), [IBuildingAxes::Add](ibuildingaxes_add.html).
