Синтаксис Automation:

BOOL MakeAsVariant( BSTR VariantName );

Синтаксис COM:

HRESULT MakeAsVariant( BSTR VariantName, BOOL * Result );

Возвращаемое значение:

TRUE | \- исполнение является вариантом геометрии,  
---|---  
FALSE | \- обычное исполнение.  
  
Входные параметры:

VariantName | \- наименование варианта геометрии.  
---|---
