Иерархия:

IDispatch

[IBoundariesObject](iboundariesobject.html)

Описание:

Позволяет редактировать границы объекта. Дополнительный интерфейс штриховки [IHatch](ihatch.html), заливки [IColouring](icolouring.html) и растрового объекта [IRaster](iraster.html).

Примечание:

Данный интерфейс можно получить с помощью метода [IUnknown::QueryInterface](recomendation.html).
