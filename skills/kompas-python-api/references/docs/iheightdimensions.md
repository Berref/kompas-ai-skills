Описание:

Интерфейс позволяет получать и создавать размеры высоты.

Примечание:

Данный интерфейс можно получить у контейнера условных обозначений, используя свойство [ISymbols2DContainer::HeightDimensions](isymbols2dcontainer_heightdimensions.html).
