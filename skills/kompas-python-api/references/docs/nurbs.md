Аналог данной функции при использовании Automation - метод [ksDocument2D::ksNurbs](ksdocument2d_ksnurbs.html).

Синтаксис:

int Nurbs (unsigned char degree,

unsigned char close,

unsigned int style);

Входные параметры:

degree | \- порядок NURBS (степень полинома + 1), от 3 до 10,  
---|---  
close | \- признак замыкания сплайна: FALSE - незамкнутый, TRUE - замкнутый,  
style | стиль линии.  
  
[Системные стили линий...](lstyles.html)

Возвращаемое значение:

1 | \- в случае успешного завершения,  
---|---  
0 | \- в случае неудачи.  
  
Примечание:

1\. Узлы кривой определяются следующими далее функциями [Point](point.html) или [NurbsPoint](nurbspoint.html). Описание кривой завершается функцией [EndObj](endobj.html), возвращающей указатель на созданную кривую.

2\. Объект создается в текущем слое текущего вида.

3\. В качестве стиля линии можно задавать номер предопределенного (системного LStyles) или пользовательского стиля линии.
