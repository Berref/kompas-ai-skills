Тип данных: указатель на интерфейс [IText](itext.html)

Синтаксис Automation:

Text = Object.Text | Получить свойство([* ](1.html))  
---|---  
Text = Object.GetText() | Получить свойство ([**](2.html))  
  
Синтаксис COM:

Object.get_Text( &Text ) | Получить свойство  
---|---  
  
Примечание:

1\. Свойство доступно только для чтения.

2\. Свойство позволяет получить указатель на интерфейс текста [IText](itext.html) для редактирования текста базы.

3\. Указатель на интерфейс [IText](itext.html) вернётся только в случае отключенной опции [Автосортировка](ibase_autosorted.html). Если автосортировка текста включена, свойство вернёт NULL.
