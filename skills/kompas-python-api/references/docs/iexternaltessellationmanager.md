IExternalTessellationManager | \- интерфейс Automation  
---|---  
  
Описание:

Дополнительный интерфейс для [IKompasDocument3D](ikompasdocument3d.html).

Данный интерфейс можно получить у интерфейса IKompasDocument3D посредством вызова метода [IUnknown::QueryInterface (const GUID far& IID, void** pif)](recomendation.html).

Примечание:

Позволяет создавать объекты с внешней триангуляцией, отрисовываемые треугольниками и ребрами.
