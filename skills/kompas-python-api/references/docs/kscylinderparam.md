---|---

Описание:

Цилиндрическая поверхность определяется системой координат, радиусом и высотой. Оси X и Y лежат в плоскости основания.

Примечание:

Данный интерфейс может быть получен с использованием метода интерфейса [ksSurface::GetSurfaceParam](kssurface_getsurfaceparam.html).
