Тип данных: указатель на интерфейс марки [IMark](imark.html)

Синтаксис Automation:

Mark = iObject.Mark(index) | Получить свойство([* ](1.html))  
---|---  
Mark = iObject.GetMark(index) | Получить свойство ([**](2.html))  
  
Синтаксис COM:

iObject->get_Mark(index, &Mark) | Получить свойство  
---|---  
  
Входные параметры:

Index (Variant) | \- Индекс.  
---|---  
  
Примечание:

1\. Свойство доступно только для чтения.

2\. В качестве индекса могут использоваться следующие типы:

•Индекс объекта в коллекции,

•Сcылка на объект (reference),

•Cуммарная строка – имя ([IMark::Name)](imark_name.html) \+ номер марки ([IMark::Number)](imark_number.html) без дополнительных разделителей.

Пример:

mark = iMarks.Mark("A1");

где "А" - имя марки

"1" - номер марки

(отсутствуют)
