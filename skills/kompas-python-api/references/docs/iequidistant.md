Интерфейс эквидистанты.

Иерархия:

IDispatch

[IKompasAPIObject](ikompasapiobject.html)

[IDrawingObject](idrawingobject.html)

[IEquidistant](iequidistant.html)

Описание:

Интерфейс позволяет задавать параметры эквидистанты.

Примечание:

1\. Интерфейс можно получить у коллекции эквидистант, используя свойство [IEquidistants::Equidistant](iequidistants_equidistant.html) или метод [IEquidistants::Add](iequidistants_add.html).

2\. После задания параметров эквидистанты требуется вызвать метод [IDrawingObject::Update](idrawingobject_update.html).
