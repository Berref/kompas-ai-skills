Синтаксис Automation:

BSTR ksGetZona (double x,

double y,

long* res);

Входные параметры:

x, y | \- координаты точки в текущем документе.  
---|---  
  
Выходной параметр:

res | результат работы метода: 0 - ошибка (например, точка вне документа или документ - не чертеж), -1 - в текущем документе нет разбиения на зоны; 1 - успешное завершение.  
---|---  
  
Возвращаемое значение:

| \- строка с названием зоны.
