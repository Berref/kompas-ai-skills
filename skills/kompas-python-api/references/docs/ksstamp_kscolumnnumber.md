Синтаксис Automation:

long ksColumnNumber (long numb);

Входной параметр:

numb | \- номер ячейки основной надписи.  
---|---  
  
Возвращаемое значение:

1 | \- в случае успешного завершения,  
---|---  
0 | \- в случае неудачи.  
  
Примечание:

Метод используется в режиме редактирования основной надписи.
