Описание:

Элемент управления состоит из текстового поля и кнопки вызова диалога открытия файла.

Примечание:

1\. Данный интерфейс можно получить, используя коллекцию элементов управления Панели свойств [IPropertyControls](ipropertycontrols.html).

1\. При изменении значения параметра вызывается событие [ksPropertyManagerNotify::ChangeControlValue](kspropertymanagernotify_changecontrolvalue.html).
