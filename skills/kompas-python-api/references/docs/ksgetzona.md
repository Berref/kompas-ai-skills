Аналог данной функции при использовании Automation - метод [ksDocument2D::ksGetZona](ksdocument2d_ksgetzona.html).

Синтаксис:

int ksGetZona (double x,

double y,

char * zona,

int size);

Входные параметры:

x, y | \- координаты точки в текущем документе.  
---|---  
size | \- размер буфера.  
  
Выходной параметр:

zona | \- буфер для возврата зоны,  
---|---  
  
Возвращаемое значение:

1 | \- успешное завершение,  
---|---  
0 | \- ошибка (например, точка вне документа или документ - не чертеж),  
-1 | \- в текущем документе нет разбиения на зоны.  
  
Примечание.

При использовании Unicode следует использовать функцию [ksGetZonaW](ksgetzonaw.html).
