Иерархия:

IDispatch

[ILineSegmentAndPointDimension](ilinesegmentandpointdimension.html)

Примечание:

Интерфейс является дополнительным для линейного размера [ILineDimension](ilinedimension.html), созданным командой Линейный от отрезка до точки

Для создания размера от отрезка до точки требуется воспользоваться методом [ILineDimensions::AddLineSegmentAndPointDimension](ilinedimensions_addlinesegmentandpointdimension.html).
