Описание:

Интерфейс позволяет получать и создавать диаметральные размеры.

Примечание:

Данный интерфейс можно получить у контейнера условных обозначений, используя свойство [ISymbols2DContainer::DiametralDimensions](isymbols2dcontainer_diametraldimensions.html).
