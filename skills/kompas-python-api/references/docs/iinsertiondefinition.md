Описание вставки фрагмента или вида.

Иерархия:

IDispatch

[IKompasAPIObject](ikompasapiobject.html)

[IInsertionDefinition](iinsertiondefinition.html)

Описание:

Интерфейс позволяет задавать и получать параметры описания вставки фрагмента или вида.

Примечание:

Данный интерфейс можно получить следующими способами:

•с помощью метода [IInsertionObject::InsertionDefinition](iinsertionobject_insertiondefinition.html).

•с помощью метода [IInsertionsManager::InsertionDefinition](iinsertionsmanager_insertiondefinition.html).
