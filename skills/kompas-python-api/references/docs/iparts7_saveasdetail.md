Синтаксис Automation:

LPDISPATCH SaveAsDetail( VARIANT Objects, LPDISPATCH Param );

Синтаксис COM :

HRESULT SaveAsDetail( VARIANT Objects, ISaveAsDetailParam * Param, IPart7 * * Result );

Возвращаемое значение:

| \- указатель на интерфейс новой вставки [IPart7](ipart7.html).  
---|---  
  
Входные параметры:

Objects | \- Список SafeArray VT_ARRAY | VT_DISPATCH объектов, передаваемых в новый документ,  
---|---  
Param | \- Параметры создания нового документа.  
  
Примечание

Функция является аналогом команды Компас Преобразовать в деталь/локальную деталь.

Преобразование в деталь/локальную деталь возможно только для объектов, построенных непосредственно в текущей модели (для локальной детали — только в текущей сборке) и относящихся к следующим типам:

•тела,

•поверхности,

•пространственные кривые и точки,

•локальные системы координат,

•вспомогательные плоскости,

•вспомогательные оси.

Объекты могут быть как перемещены, так и скопированы в новый документ.

Версия: Компас v20
