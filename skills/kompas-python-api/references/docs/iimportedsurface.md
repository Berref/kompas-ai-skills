Интерфейс можно получить у интерфейса коллекции импортированных поверхностей с помощью свойства [IImportedSurfaces::ImportedSurface](iimportedsurfaces_importedsurface.html) или метода [IImportedSurfaces::Add](iimportedsurfaces_add.html).

С помощью метода [IUnknown::QueryInterface](recomendation.html) у интерфейса можно получить интерфейс подчиненного объекта ЛСК [ILocalCSObject](ilocalcsobject.html).
