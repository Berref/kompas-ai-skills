Описание:

Интерфейс позволяет получать и создавать линейные размеры.

Примечание:

Данный интерфейс можно получить у контейнера условных обозначений, используя свойство [ISymbols2DContainer::LineDimensions](isymbols2dcontainer_linedimensions.html).
