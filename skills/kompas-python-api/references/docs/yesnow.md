# YesNoW - Подтвердить действие или отказаться от него (Unicode)

[API экспортных функций](export_function.html) > [Функции работы с прикладной библиотекой ](cn1731963.html) > [Функции вывода на экран ](screen_output_fncts_common.html) |  Scroll [ [ [ ](serv_lib_func_common.html "К следующему разделу")](screen_output_fncts_common.html "На уровень выше")](yesno.html "К предыдущему разделу")  
---|---  
  
Аналог данной функции при использовании Automation - метод [KompasObject::ksYesNo](kompasobject_ksyesno.html).

Синтаксис:

int LIB_FUNC YesNoW( LPWSTR s );

Входной параметр:

s | \- строка сообщения.  
---|---  
  
Возвращаемое значение:

1 | \- при подтверждении действия,  
---|---  
0 | \- при отказе,  
-1 | \- при отмене действия.  
  
Примечание:

1\. Подтверждение означает нажатие в диалоге кнопки Да (Yes, OK); отказ - нажатие кнопки Нет (No); отмена действия - нажатие кнопки Отмена (Cansel).

2\. При использовании ANSI следует использовать функцию [YesNo](yesno.html).
