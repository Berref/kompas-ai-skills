Синтаксис Automation:

Синтаксис COM:

HRESULT SaveAs ([in] BSTR PathName);

Входные параметры:

PathName | \- полное имя файла документа, состоящее из пути, имени и расширения файла.

Примечание:

Позволяет сохранить документ на диск под другим именем.
