Примечание:

Все, определяемые далее до вызова функции [EndObj,](endobj.html) геометрические примитивы чертежа (отрезки, дуги, кривые) будут включены в контур. Контур должен быть непрерывным - начальная точка очередного объекта обязана совпадать с конечной точкой предыдущего. Полученный контур может быть использован для построения эквидистанты. Функция EndObj возвращает указатель на созданный макроэлемент.
