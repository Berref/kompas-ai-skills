Синтаксис Automation:

long ksParametrizeObjects (long group, LPDISPATCH par);

Входные параметры:

group | \- указатель на группу объектов,  
---|---  
par | \- параметры параметризации группы объектов [ksParametrizationParam](ksparametrizationparam.html).  
  
Возвращаемое значение:

1 | \- в случае успеха,  
---|---  
0 | \- в случае неудачи.
