Интерфейс используется для операций:

o3d_mirrorOperation | 48 | Зеркальный массив операций  
---|---|---  
o3d_mirrorAllOperation | 49 | Операция «зеркально отразить тело или поверхность»; дополнительно имеет интерфейс выбора тел [IChooseBodies7](ichoosebodies7.html)  
o3d_AuxMirrorOperation | 509 | Зеркальный массив вспомогательной геометрии  
  
Интерфейс можно получить в коллекции массивов [IFeaturePatterns](ifeaturepatterns.html).
