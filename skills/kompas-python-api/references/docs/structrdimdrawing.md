Аналог данных параметров при использовании Automation - интерфейс [ksRDimDrawingParam](ksrdimdrawingparam.html).

unsigned char | pt1 | тип стрелки у первой выносной линии,  
---|---|---  
unsigned char | pt2 | диаметральный размер: тип стрелки у второй выносной линии, радиальный размер: 0 - размер от центра, 1 - не от центра,  
int | textPos | параметр отрисовки текста или длина ножки; аннотационный (не зависит от масштаба),  
int | shelfDir | наличие горизонтальной выносной полки: (0 - нет выносной полки, -1 - полка направлена влево, 1 - полка направлена вправо, 2 - полка направлена вверх, 3 - полка направлена вниз),  
double | ang | угол наклона размерной линии.
