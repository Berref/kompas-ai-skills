Описание:

Интерфейс позволяет получить и создавать радиальные размеры в 3D документе.

Данный интерфейс можно получить у контейнера условных обозначений, используя свойство [ISymbols3DContainer::RadialDimensions3D](isymbols3dcontainer_radialdimensions3d.html).
