# ReadLongW - Ввести длинное целое число с контролем попадания значения в заданный интервал (Unicode)

[API экспортных функций](export_function.html) > [Функции работы с прикладной библиотекой ](cn1731963.html) > [Функции ввода параметров ](enter_params_common.html) |  Scroll [ [ [ ](readstring.html "К следующему разделу")](enter_params_common.html "На уровень выше")](readlong.html "К предыдущему разделу")  
---|---  
  
Синтаксис:

int LIB_FUNC ReadLongW (LPWSTR smess, long def, long min, long max, long *value);

Входные параметры:

smess | \- строка приглашения,  
---|---  
def | \- предлагаемое значение по умолчанию,  
min,max | \- интервал возможных значений,  
R | \- результат ввода.  
  
Возвращаемое значение:

1 | \- в случае удачного завершения,  
---|---  
0 | \- в случае неудачи.  
  
Примечание.

При использовании ANSI следует использовать функцию [ReadLong](readlong.html).
