Интерфейс многоугольника.

Иерархия:

IDispatch

[IKompasAPIObject](ikompasapiobject.html)

[IDrawingObject](idrawingobject.html)

[IRegularPolygon](iregularpolygon.html)

Описание:

Интерфейс позволяет задавать параметры многоугольника.

Примечание:

1\. Интерфейс можно получить у коллекции многоугольников, используя свойство [IRegularPolygons::RegularPolygon](iregularpolygons_regularpolygon.html) или метод [IRegularPolygons::Add](iregularpolygons_add.html).

2\. После задания параметров многоугольника требуется вызвать метод [IDrawingObject::Update](idrawingobject_update.html).
