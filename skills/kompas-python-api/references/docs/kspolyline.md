Аналог данной функции при использовании Automation - метод [ksDocument2D::ksPolyline](ksdocument2d_kspolyline.html).

Синтаксис:

int ksPolyline (unsigned short style);

Входной параметр:

style | стиль линии.  
---|---  
  
[Системные стили линий...](lstyles.html)

Возвращаемое значение:

1 | \- в случае удачного завершения,  
---|---  
0 | \- в случае неудачи.  
  
Примечание:

Узлы определяются следующими далее функциями [Point](point.html). Описание завершается функцией [EndObj](endobj.html), возвращающей указатель на созданный объект. Объект создается в текущем слое текущего вида. В качестве стиля линии можно задавать номер предопределенного ([системного](lstyles.html)) или пользовательского стиля линии.
