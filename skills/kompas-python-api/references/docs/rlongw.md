# RLongW - Определить в отношении поле типа int или long int (Unicode)

[API экспортных функций](export_function.html) > [Функции работы с прикладной библиотекой ](cn1731963.html) > [Функции работы с базами данных ](db_obj_fncts_common.html) |  Scroll [ [ [ ](readrecord.html "К следующему разделу")](db_obj_fncts_common.html "На уровень выше")](rlong.html "К предыдущему разделу")  
---|---  
  
Аналог данной функции при использовании Automation - метод [ksDataBaseObject::ksRLong](ksdatabaseobject_ksrlong.html).

Синтаксис:

int LODBC_FUNC RLongW (LPWSTRname);

Входной параметр:

name | \- имя поля.  
---|---  
  
Возвращаемое значение:

1 | \- в случае успешного завершения,  
---|---  
0 | \- в случае неудачи.  
  
Примечание:

1\. Параметр name действителен только при работе с текстовыми базами данных.

2\. При использовании ANSI следует использовать функцию [RLong](rlong.html).
