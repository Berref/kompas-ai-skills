Аналог данной функции при использовании Automation - метод [ksDocument2D::ksBase](ksdocument2d_ksbase.html).

Синтаксис:

reference BaseW (BaseParamW *basePar);

Выходной параметр:

basePar | \- указатель на структуру параметров обозначения базы [BaseParamW](structbaseparamw.html).  
---|---  
  
Возвращаемое значение:

указатель на обозначение базы | \- в случае удачного завершения,  
---|---  
0 | \- в случае неудачи.  
  
Примечание.

При использовании ANSI следует использовать функцию [Base](base.html).
