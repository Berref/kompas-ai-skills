Тип данных: из перечисления [ksObj3dTypeEnum](obj3dtype.html)

Синтаксис Automation:

AxisType = Object.AxisType | Получить свойство ([* ](1.html))  
---|---  
Object.AxisType = AxisType | Установить свойство ([* ](1.html))  
AxisType = Object.GetAxisType() | Получить свойство ([**](2.html))  
Object.SetAxisType( AxisType ) | Установить свойство ([**](2.html))  
  
Синтаксис COM:

Object.get_AxisType( &AxisType ) | Получить свойство  
---|---  
Object.put_AxisType( AxisType ) | Установить свойство  
  
Свойство позволяет устанавливать и получать тип оси (Х, Y, Z).

Примечание:

Тип оси также определяет плоскость размещения вектора.
