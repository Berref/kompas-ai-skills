Аналог данного метода при использовании API экспортных функций - [ksAddPowerForm](ksaddpowerform.html).

Синтаксис Automation:

long ksAddPowerForm (double x, double y);

Входные параметры:

x, y | \- параметры степенной функции (см. Примечание).  
---|---  
  
Возвращаемое значение:

1 | \- в случае успешного завершения,  
---|---  
0 | \- в случае неудачи.  
  
Примечание:

Кусочно-степенная форма состоит из последовательности стыкующихся полиномов:

P0 [0, 1), P1 [1, 2), ... Pk [k, k1),

где Pi - полином, [i, i1) - интервал определения,

Pi( t ).x = a0.x a1.x * (t - i) a2.x * (t - i) * (t - i) ... an.x * (t - i)^n

Pi( t ).y = a0.y a1.y * (t - i) a2.y * (t - i) * (t - i) ... an.y * (t - i)^n

Функция ksAddPowerForm должна вызываться последовательно n1 раз для пар параметров (a0.x, a0.y), (a1.x, a1.y), ... (an.x, an.y).

Затем вызывается функция [ksCreatePowerArc](ksdocument2d_kscreatepowerarc.html), которая создает из переданных параметров дугу NURBS степени n 1 и присоединяет ее к существующей кривой NURBS.
