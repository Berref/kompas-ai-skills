Интерфейс всплывающей контекстной панели.

Иерархия:

IDispatch

[IContextPanel](icontextpanel.html)

Описание:

Интерфейс используется для создания всплывающей панели для библиотечных элементов.

Для использования всплывающих панелей в библиотеке требуется реализовать функцию:

int WINAPI FillContextPanel( LPUNKNOWN contextPanel );

Версия: Компас v20
