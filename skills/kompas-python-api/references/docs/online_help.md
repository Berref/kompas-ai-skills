В КОМПАС-3D реализован механизм использования онлайн-справки. Опция Использовать онлайн-справку доступна в меню Настройка — Параметры... — Общие — Справка. 

![warn](./images/warn.png) | Вызов онлайн-справки приложения производится согласно базовой настройке КОМПАС-3D Справка — Использовать онлайн-справку.  
---|---  
  
Адресом онлайн-справки КОМПАС-3D и приложений по умолчанию является [help.ascon.ru](http://help.ascon.ru/).
