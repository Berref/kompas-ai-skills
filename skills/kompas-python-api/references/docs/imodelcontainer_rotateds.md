Тип данных: указатель на интерфейс коллекции операций вращения [IRotateds.](irotateds.html)

Синтаксис Automation:

Rotateds = Object.Rotateds | Получить свойство ([* ](1.html))  
---|---  
Rotateds = Object.GetRotateds() | Получить свойство ([**](2.html))  
  
Синтаксис COM:

Object.get_Rotateds( &Rotateds ) | Получить свойство  
---|---  
  
Свойство позволяет получить коллекцию всех операций вращения, входящих в состав данного объекта.

Примечание:

Свойство доступно только для чтения.
