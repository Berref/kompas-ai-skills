Примечание:

1\. Интерфейс позволяет реализовать отрисовку внешних GDI- объектов (для V11 только текстов).

2\. Управление интерфейсом (создание и удаление) осуществляется через менеджер [IExternalTessellationManager](iexternaltessellationmanager.html).
