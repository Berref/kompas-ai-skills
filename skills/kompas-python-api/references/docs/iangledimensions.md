Интерфейс коллекции угловых размеров.

Иерархия:

[IKompasAPIObject](ikompasapiobject.html)

[IKompasCollection](ikompascollection.html)

[IDrawingObjects](idrawingobjects.html)

[IAngleDimensions](iangledimensions.html)

Описание:

Интерфейс позволяет получать и создавать угловые размеры.

Примечание:

1\. Коллекция содержит угловые и угловые с обрывом размеры.

2\. Данный интерфейс можно получить у контейнера условных обозначений, используя свойство [ISymbols2DContainer::AngleDimensions](isymbols2dcontainer_angledimensions.html).
