Синтаксис COM:

Чтобы получить интерфейс документа трехмерной модели при программировании на COM, нужно использовать экспортную функцию [ksGet3dDocument](ksget3ddocument.html).

Возвращаемое значение:

| \- указатель на интерфейс документа трехмерной модели [IIDocument3D](ksdocument3d.html).
