Тип данных: BOOL

Значения свойства:

TRUE | \- вдоль поверхности,  
---|---  
FALSE | \- по направлению от вершины.  
  
Синтаксис Automation:

OnFace = Object.OnFace | Получить свойство ([* ](1.html))  
---|---  
Object.OnFace = OnFace | Установить свойство ([* ](1.html))  
OnFace = Object.GetOnFace() | Получить свойство ([**](2.html))  
Object.SetOnFace( OnFace ) | Установить свойство ([**](2.html))

Object.get_OnFace( &OnFace ) | Получить свойство  
---|---  
Object.put_OnFace( OnFace ) | Установить свойство
