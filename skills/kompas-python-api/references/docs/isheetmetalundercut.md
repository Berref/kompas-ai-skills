[ISheetMetalUndercut](isheetmetalundercut.html)

Интерфейс является дополнительным к интерфейсу [ISheetMetalLineBend](isheetmetallinebend.html) для операций подсечка создаваемых через коллекцию [ISheetMetalContainer::SheetMetalUndercuts](isheetmetalcontainer_sheetmetalundercuts.html).

Данный интерфейс можно получить посредством вызова метода [IUnknown::QueryInterface](recomendation.html) (const GUID far& iid, void** pif).
