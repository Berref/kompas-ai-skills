Интерфейс параметров шрифта.

Иерархия:

[IKompasAPIObject](ikompasapiobject.html)

[ITextFont](itextfont.html)

Описание:

Данный интерфейс позволяет назначить параметры шрифта, которые будут использоваться при вводе надписей в документ.

Примечание:

1\. Данный интерфейс можно получить от интерфейса параметров стиля текста [ITextStyle](itextstyle.html), используя свойство[ ITextStyle::Font](itextstyle_font.html).

2\. Интерфейс ITextFont является дополнительным для интерфейса [ITextItem](itextitem.html).
