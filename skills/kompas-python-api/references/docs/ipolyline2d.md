Интерфейс полилинии (ломаной).

Иерархия:

IDispatch

[IKompasAPIObject](ikompasapiobject.html)

[IDrawingObject](idrawingobject.html)

[IPolyLine2D](ipolyline2d.html)

Описание:

Интерфейс позволяет задавать параметры ломаной.

Примечание:

1\. Интерфейс можно получить у коллекции полилиний, используя свойство [IPolyLines2D::PolyLine2D](ipolylines2d_polyline2d.html) или метод [IPolyLines2D::Add](ipolylines2d_add.html).

2\. После задания параметров полилинии требуется вызвать метод [IDrawingObject::Update](idrawingobject_update.html).
