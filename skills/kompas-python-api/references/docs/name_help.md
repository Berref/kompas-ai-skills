Поиск справки выполняется по следующему правилу:

<helpId>_<локаль>.zip

Если ключ [helpid](key_for_help.html#key_helpid) не задан в манифесте приложения, то поиск справки выполняется по правилу:

<application ID>_<локаль>.zip
