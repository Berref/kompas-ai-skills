# Типы библиотек системы КОМПАС

[Создание прикладных библиотек ](libraries_create.html) |  Scroll [ [ [ ](libdlltype_library_status.html "К следующему разделу")](libraries_create.html "На уровень выше")](kompas_libs.html "К предыдущему разделу")  
---|---  
  
•Простые библиотеки. Такие библиотеки пользователь может отключать или подключать к системе КОМПАС по собственному желанию. Библиотеки отображаются в менеджере библиотек.

•Библиотеки-добавления типа Addins. Такие библиотеки подключаются к системе КОМПАС во время запуска системы автоматически. В менеджере библиотек не отображаются, но видны в меню Библиотеки. Для того, чтобы библиотека стала добавляемой, нужно зарегистрировать ее в реестре Windows [определенным образом](addin_example.html).

•Библиотеки-конверторы. Такие библиотеки регистрируются [определенным образом в реестре](libdlltype_converter_example.html) и должны реализовывать интерфейс [IKompasConverter](ikompasconverter.html) (см. sdk\libs\ConvertLibInterfaces.tlb и пример MyConverter).

В системе КОМПАС под команды библиотек зарезервировано 10000 уникальных номеров. Максимальное число одновременно подключенных библиотек равно 25. Максимальное число инструментальных панелей библиотек равно 50.
