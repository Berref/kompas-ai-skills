Примечание:

1\. Вместо стандартного вида элемента управления можно задать значки для его различных состояний.

2\. Данный интерфейс можно получить через интерфейс коллекции элементов управления панели свойств [IPropertyControls](ipropertycontrols.html).

3\. При активизации элемента управления вызывается событие [ksIPropertyManagerNotify::ChangeControlValue](kspropertymanagernotify_changecontrolvalue.html).
