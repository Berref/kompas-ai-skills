Синтаксис:

VARIANT_BOOL FillContextPanel( LPDISPATCH ContextPanel );

Входные параметры:

ContextPanel | \- указатель на интерфейс всплывающей панели [IContextPanel](icontextpanel.html).  
---|---  
  
Возвращаемое значение:

TRUE | \- если были изменения контекстной панели,  
---|---  
FALSE | \- использовать стандартную накачку панелей для данного библиотечного элемента.
