Интерфейс параметров вида.

Аналог данных параметров при использовании API экспортных функций - [ViewParam](structviewparam.html).

Примечание:

1\. Указатель на интерфейс должен быть получен с помощью метода [KompasObject::GetParamStruc](kompasobject_getparamstruct.html)t с параметром ko_ViewParam.

2\. Параметры могут быть получены с помощью метода [ksDocument2D::ksGetObjParam](ksdocument2d_ksgetobjparam.html) с параметром ALLPARAM.

Смотрите также: [KompasObject](kompasobject.html)
