# Функции работы с макроэлементами и библиотечными макроэлементами

Библиотечный макроэлемент - это макроэлемент, имеющий пользовательские параметры.

Пользовательские параметры могут быть записаны в макроэлемент при помощи функции [ksSetMacroParam](kssetmacroparam.html).

Также при помощи функции ksSetMacroParam может быть включен режим управления характерными точками макроэлемента (поддержка макроэлементом интерфейса [ILibHPObject](ilibhpobject.html) ), отработка событий внешних воздействий на макроэлемент (поддержка макроэлементом интерфейса [ILibExternalObject](ilibexternalobject.html)), выключен\включен режим редактирования макроэлемента по двойному щелчку мыши.

Получить пользовательские параметры можно при помощи функции [GetMacroParam](getmacroparam.html).
