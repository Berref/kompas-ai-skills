Интерфейс частей тела.

Иерархия:

IDispatch

[IBodyParts7](ibodyparts7.html)

Описание:

Некоторые операции в 3D позволяют создавать несколько частей результирующего тела.

Интерфейс позволяет получить информацию о частях тела и управлять их включением в расчет и исключением из расчета.

Желательно включить части таким образом, чтобы тело оказалось целым.

Данный интерфейс можно получить, используя метод интерфейса элемента модели [IModelObject1::BodyParts](imodelobject1_bodyparts.html).
