Тип данных: указатель на интерфейс обозначения базы [IBase](ibase.html)

Синтаксис Automation:

Base = iObject.Base( Index ); | Получить свойство([* ](1.html))  
---|---  
Base = iObject.GetBase( Index ); | Получить свойство ([**](2.html))  
  
Синтаксис COM:

iObject->get_Base( Index, &Base ) | Получить свойство  
---|---  
  
Входные параметры:

Index (Variant) | \- Индекс узла в коллекции. Поддерживаются следующие типы: \- VT_I4 - индекс обозначения базы.  
---|---  
  
Примечание:

1\. Свойство доступно только для чтения.

2\. В качестве индекса может использоваться индекс в коллекции и reference объекта.
