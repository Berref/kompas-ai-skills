Интерфейс волнистой линии.

Иерархия:

IDispatch

[IKompasAPIObject](ikompasapiobject.html)

[IDrawingObject](idrawingobject.html)

[IWaveLine](iwaveline.html)

Описание:

Интерфейс позволяет задавать и получать параметры волнистой линии.

Примечание:

1\. Интерфейс можно получить у коллекции волнистых линий, используя свойство [IWaveLines::WaveLine](iwavelines_waveline.html) или метод [IWaveLines::Add](iwavelines_add.html).

2\. После задания параметров объекта требуется вызвать метод [IDrawingObject::Update](idrawingobject_update.html).
