[IKompasAPIObject](ikompasapiobject.html)

[IVector3DAlongSurfaceNormalParameters](ivector3dalongsurfacenormalparameters.html)

Интерфейс позволяет устанавливать и получать параметры вектора, перпендикулярного грани в указанной точке.

Интерфейс можно получить у интерфейса вектора с помощью свойства [IVector3D::Parameters](ivector3d_parameters.html).
