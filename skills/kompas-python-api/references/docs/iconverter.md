Конвертер файлов КОМПАС.

Иерархия:

[IKompasAPIObject](ikompasapiobject.html)

[IConverter](iconverter.html)

Примечание:

1\. Интерфейс позволяет управлять конвертером системы КОМПАС, задавать параметры конвертирования, получать фильтр и выполнять конвертацию документа системы КОМПАС.

2\. Данный интерфейс может быть получен от интерфейса приложения [IApplication](iapplication.html) с помощью свойства [IApplication::Converter](iapplication_converter.html).
