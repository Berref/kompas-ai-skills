Интерфейс кривых пересечений поверхностей.

Иерархия:

[IKompasAPIObject](ikompasapiobject.html)

[IModelObject](imodelobject.html)

[ISurfacesIntersectionCurve](isurfacesintersectioncurve.html)

Описание:

Интерфейс позволяет создать кривую пересечения двух поверхностей, или двух наборов поверхностей, или поверхности и набора.

Примечание:

Интерфейс можно получить с помощью свойства [ISurfacesIntersectionCurves::SurfacesIntersectionCurve](isurfacesintersectioncurves_surfacesintersectioncurve.html) и метода [ISurfacesIntersectionCurves::Add](isurfacesintersectioncurves_add.html).
