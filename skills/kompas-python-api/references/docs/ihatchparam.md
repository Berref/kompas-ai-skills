Иерархия:

IDispatch

[IHatchParam](ihatchparam.html)

Описание:

Примечание:

1\. Интерфейс является дополнительным для [IHatch](ihatch.html) и [IAssociationView](iassociationview.html).

2\. Интерфейс можно получить с помощью метода [ICutViewParam::HatchParam](icutviewparam_hatchparam.html).
