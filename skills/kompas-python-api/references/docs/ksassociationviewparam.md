Интерфейс параметров ассоциативного вида.

Аналог данного интерфейса при использовании API экспортных функций - [AssociationViewParam](structassociationviewparam.html).

Примечание:

1\. Указатель на интерфейс должен быть получен с помощью метода [KompasObject::GetParamStruct](kompasobject_getparamstruct.html) с параметром ko_AssociationViewParam.

2\. Параметры могут быть получены с помощью метода [ksDocument2D::ksGetObjParam](ksdocument2d_ksgetobjparam.html) с параметром ASSOCIATION_VIEW_PARAM.
