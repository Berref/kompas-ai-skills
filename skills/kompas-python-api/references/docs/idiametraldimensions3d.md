Описание:

Интерфейс позволяет получить и создавать диаметральные размеры в 3D документе.

Данный интерфейс можно получить у контейнера условных обозначений, используя свойство [ISymbols3DContainer::DiametralDimensions3D](isymbols3dcontainer_diametraldimensions3d.html).
