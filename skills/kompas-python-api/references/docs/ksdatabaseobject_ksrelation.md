Аналог данного метода при использовании API экспортных функций - [Relation](relation.html).

Синтаксис Automation:

long ksRelation (long db);

Входной параметр:

db | \- указатель на объект БД.  
---|---  
  
Возвращаемое значение:

указатель на отношение | \- в случае успешного завершения,  
---|---  
0 | \- в случае неудачи.  
  
Примечание:

Отношение характеризует один запрос и представляет собой Описание памяти, необходимой для размещения очередной записи выборки, выполняемого функцией [ksDataBaseObject::ksReadRecord](ksdatabaseobject_ksreadrecord.html). Является составным объектом, каждое поле которого описывает тип и имя поля (колонки) в таблице базы данных. Имя действительно только в случае работы с текстовым файлом, так как при обмене через ODBC-интерфейс имена уже описаны в блоке заголовка.

Количество отношений, определенных для базы данных, не ограничивается.
