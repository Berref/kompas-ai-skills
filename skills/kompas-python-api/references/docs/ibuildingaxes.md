Интерфейс коллекции строительных (координационных) осей.

Иерархия:

[IKompasAPIObject](ikompasapiobject.html)

[IKompasCollection](ikompascollection.html)

Описание:

Интерфейс позволяет получать и создавать объекты СПДС "строительные оси".

Примечание:

Получить интерфейс коллекции строительных осей можно, используя метод контейнера объектов СПДС [IBuildingContainer::BuildingAxes](ibuildingcontainer_buildingaxes.html).
