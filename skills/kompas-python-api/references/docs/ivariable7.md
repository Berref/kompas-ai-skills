Интерфейс параметрической переменной модели.

Иерархия:

[IKompasAPIObject](ikompasapiobject.html)

[IVariable7](ivariable7.html)

Описание:

Интерфейс позволяет изменять параметры объектов модели, не прибегая к их прямому редактированию. Выражения дают возможность устанавливать зависимости между параметрами объектов.

Примечание:

Интерфейс можно получить с помощью свойств:

•[IInsertionFragment::Variable](iinsertionfragment_variable.html),

•[IInsertionFragment::Variables](iinsertionfragment_variables.html),

•[IKompasDocument2D1::Variable](ikompasdocument2d1_variable.html),

•[IKompasDocument2D1::Variables](ikompasdocument2d1_variables.html),

•[IView::Variable](iview_variable.html),

•[IView::Variables](iview_variables.html)

и метода:

•[IKompasDocument2D1::AddVariable](ikompasdocument2d1_addvariable.html).
