Аналог данной функции при использовании Automation - метод [ksDocument2D::ksSpecRough](ksdocument2d_ksspecrough.html).

Синтаксис:

int SpecRough (unsigned char type, unsigned char t, char * s);

Входные параметры:

type | \- тип знака 0 - вид обработки не устанавливается 1 - обработка удалением слоя материала 2 - обработка без удаления слоя материала  
---|---  
t | \- наличие знака в скобках (1 - есть, 0 - нет).  
  
Выходные параметры:

s | \- строка текста.  
---|---  
  
Возвращаемое значение:

1 | \- в случае удачного завершения,  
---|---  
0 | \- в случае неудачи.
