Иерархия:

Описание:

Настройки могут быть для текущего документа (можно получить у документа) и для новых документов (можно получить у приложения).

Примечание:

Данный интерфейс можно получить от интерфейса документа [IKompasDocument](ikompasdocument.html) с помощью свойства [IKompasDocument::DocumentSettings](ikompasdocument_documentsettings.html).
