Интерфейс параметров наложения текстур.

Иерархия:

IDispatch

[ITexturesParam](itexturesparam.html)

Интерфейс является дополнительным для интерфейса [IColorParam7](icolorparam7.html) объектов [IModelObject](imodelobject.html). [IPart7](ipart7.html), [IBody7](ibody7.html),[ILayer3D](ilayer3d.html).

Для установки параметров отображения текстур для объектов модели требуется, чтобы у объекта был установлен признак использования собственного цвета,

т.е. свойство [IColorParam7::UseColor](icolorparam7_usecolor.html) требуется установить равным useColorOur.

Версия: KOMPAS v19
