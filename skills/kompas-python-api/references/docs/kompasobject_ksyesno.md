Аналог данного метода при использовании API экспортных функций - [YesNo](yesno.html).

Синтаксис Automation:

long ksYesNo (BSTR s);

Входной параметр:

s | \- строка сообщения.  
---|---  
  
Возвращаемое значение:

1 | \- при подтверждении действия,  
---|---  
0 | \- при отказе,  
-1 | \- при отмене действия.  
  
Примечание:

Подтверждение означает нажатие в диалоге кнопки Да (Yes, OK); отказ - нажатие кнопки Нет (No); отмена действия - нажатие кнопки Отмена (Cansel).
