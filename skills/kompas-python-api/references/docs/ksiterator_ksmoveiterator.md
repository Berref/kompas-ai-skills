Аналог данного метода при использовании API экспортных функций - [MoveIterator](moveiterator.html).

Синтаксис Automation:

long ksMoveIterator (BSTR ch);

Входной параметр:

ch | \- направление перемещения итератора: F - первый объект, N - следующий объект.  
---|---  
  
Возвращаемое значение:

указатель на объект | \- в случае успешного завершения,  
---|---  
0 | \- в случае неудачи.  
  
Примечание:

Функция перемещает текущий указатель итератора (блока параметров навигации) на очередной объект модели. Режим позиционирования (тип объектов, участвующих в поиске) определяется при создании итератора методом [ksCreateIterator](ksiterator_kscreateiterator.html).

При позиционировании на именованную группу она автоматически становится текущей (рабочей). К ней будут относиться операции добавления и исключения объектов (при исключении всех объектов из именованной группы она автоматически удаляется).
