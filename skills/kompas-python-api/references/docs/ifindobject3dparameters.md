[IKompasAPIObject](ikompasapiobject.html)

Данный интерфейс можно получить с помощью метода [IKompasDocument1::GetInterface](ikompasdocument1_getinterface.html).

События:

см. [ksFindObject3DParametersNotify](ksfindobject3dparametersnotify.html)

Примечание:

Подписка на события [ksFindObject3DParametersNotify](ksfindobject3dparametersnotify.html) позволяет осуществить дополнительную фильтрацию объектов в функциях поиска:

[IKompasDocument3D1::PickModelObjects](ikompasdocument3d1_pickmodelobjects.html)

[IKompasDocument3D1::FindNearestObject](ikompasdocument3d1_findnearestobject.html)
