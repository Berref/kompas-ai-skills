1\. Вызвать из меню File команду New - Project, тип ActiveX DLL.

2\. Для создания КОМПАС-библиотеки необходимо вставить несколько функций.

3\. Библиотеки данного типа подключаются к КОМПАС на вкладке ActiveX, где их необходимо зарегистрировать при первом подключении, нажав кнопку Добавить.

Пример реализации простейшей библиотеки расположен в папке ..SDK\Basic\Step1 (библиотека написана с использованием [Автоматизации](automation.html)).
