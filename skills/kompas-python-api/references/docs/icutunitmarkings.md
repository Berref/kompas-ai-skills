Описание:

Интерфейс позволяет получить коллекции обозначений узла в сечении.

Примечание:

Данный интерфейс можно получить у интерфейса контейнера объектов СПДС, используя метод [IBuildingContainer::CutUnitMarkings](ibuildingcontainer_cutunitmarkings.html).
