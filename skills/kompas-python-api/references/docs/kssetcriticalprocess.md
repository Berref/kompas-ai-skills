# ksSetCriticalProcess - Установить критический процесс

Аналог данной функции при использовании Automation - метод [KompasObject::ksSetCriticalProcess](kompasobject_kssetcriticalprocess.html).

Синтаксис:

int ksSetCriticalProcess ();

Возвращаемое значение:

1 | \- в случае удачного завершения,  
---|---  
0 | \- в случае неудачи.  
  
Примечание:

Работа процесса, вызванного прикладной библиотекой (например, [Cursor](cursor.html) или [Placement](placement.html)), может быть принудительно прервана переходом к другому действию (команде). Чтобы запретить возможность принудительного прерывания такого процесса, перед его активизацией требуется вызвать данную функцию. Она сделает следующий за ней процесс "критическим", и при попытке его принудительного завершения будет выдано сообщение о необходимости корректного завершения процесса. После штатного завершения процесса признак "критического" процесса снимается, и для следующих процессов (при необходимости) функцию требуется вызывать заново.
