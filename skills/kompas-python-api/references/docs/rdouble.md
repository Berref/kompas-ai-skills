Синтаксис:

Входной параметр:

name | \- имя поля.  
---|---  
  
Возвращаемое значение:

1 | \- в случае успешного завершения,  
---|---  
0 | \- в случае неудачи.  
  
Примечание:

Параметр name действителен только при работе с текстовыми базами данных.
