Тип данных:VARIANT_BOOL.

Синтаксис:

VARIANT_BOOL Document3DWireframeShadedMode;

Примечание:

1\. Свойство изменяет тип отображения текущего документа-модели, загруженного в KGAX.

2\. Свойство работает совместно с [Document3DDrawMode](_dkgax_document3ddrawmode.html).

3\. Если установлен режим Document3DDrawMode = vt_ShadedMode и Document3DWireframeShadedMode = TRUE, то документ-модель будет отображаться в режиме Полутоновое с каркасом.
