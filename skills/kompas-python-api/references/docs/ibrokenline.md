Интерфейс линии обрыва с изломами.

Иерархия:

IDispatch

[IKompasAPIObject](ikompasapiobject.html)

[IDrawingObject](idrawingobject.html)

[IBrokenLine](ibrokenline.html)

Описание:

Интерфейс позволяет задавать и получать параметры линии обрыва с изломами.

Примечание:

1\. Интерфейс можно получить у коллекции линий обрыва с изломами используя свойство [IBrokenLines::BrokenLine](ibrokenlines_brokenline.html) или метод [IBrokenLines::Add](ibrokenlines_add.html).

2\. После задания параметров объекта требуется вызвать метод [IDrawingObject::Update](idrawingobject_update.html).
