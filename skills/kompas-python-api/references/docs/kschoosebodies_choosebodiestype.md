Примечание:

При ручном указании и автоматическом выборе тел в операции участвуют тела, которые находятся в коллекции тел области применения. Коллекцию можно получить с помощью методов [ksChooseBodies::BodyCollection](kschoosebodies_bodycollection.html) и [IChooseBodies::BodyCollection](kschoosebodies_bodycollection.html).
