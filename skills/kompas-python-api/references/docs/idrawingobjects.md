Базовый интерфейс для коллекций графических объектов.

Иерархия:

[IKompasAPIObject](ikompasapiobject.html)

[IKompasCollection](ikompascollection.html)

[IDrawingObjects](idrawingobjects.html)

Примечание:

1\. Данный интерфейс является базовым для коллекций графических объектов.

2\. Интерфейс может быть получен с помощью метода IUnknown:: QueryInterface от интерфейса коллекции конкретных объектов, например, от интерфейса видов [IViews](iviews.html), слоев [ILayers](ilayers.html).
