Параметр phType может иметь следующие значения для выбора типа фантома:

1 | \- сдвиг группы  
---|---  
2 | \- отрезок  
3 | \- прямоугольник  
4 | \- отрезок с заданным углом  
5 | \- половина прямоугольника  
6 | \- пользовательский фантом  
7 | \- окружность
