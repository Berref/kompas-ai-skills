Описание:

Интерфейс позволяет получить коллекции элементов "пространственная ломаная".

Примечание:

Получить интерфейс коллекции можно, используя свойство контейнера объектов вспомогательной геометрии [IAuxiliaryGeomContainer::PolyLines](iauxiliarygeomcontainer_polylines.html).
