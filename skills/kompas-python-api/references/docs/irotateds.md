[IRotateds](irotateds.html)

Интерфейс позволяет получать и создавать операции вращения.

Примечание

Интерфейс можно получить, используя свойство контейнера трехмерных объектов [IModelContainer::Rotateds](imodelcontainer_rotateds.html) (операции вращения и вырезания вращением) и свойство контейнера поверхностей [ISurfaceContainer::RotatedSurfaces](isurfacecontainer_rotatedsurfaces.html) (поверхность вращения).
