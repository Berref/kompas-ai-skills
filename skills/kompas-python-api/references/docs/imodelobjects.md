Базовый интерфейс для всех коллекций модельных объектов.

Иерархия:

[IKompasAPIObject](ikompasapiobject.html)

[IKompasCollection](ikompascollection.html)

[IModelObjects](imodelobjects.html)

Примечание:

1\. Данный интерфейс является базовым для коллекций модельных объектов.

2\. Интерфейс может быть получен с помощью метода IUnknown QueryInterface от коллекций модельных объектов, например, [IParts7](iparts7.html).
