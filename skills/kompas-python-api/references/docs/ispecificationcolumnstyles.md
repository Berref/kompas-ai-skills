Интерфейс коллекции стилей колонок спецификации.

Иерархия:

[IKompasAPIObject](ikompasapiobject.html)

[IKompasCollection](ikompascollection.html)

[ISpecificationColumnStyles](ispecificationcolumnstyles.html)

Описание:

Управляет массивом интерфейсов [ISpecificationColumnStyle](ispecificationcolumnstyle.html). Различаются основные и дополнительные колонки объектов спецификации.

Примечание:

1\. Чтобы получить коллекцию стилей основных колонок спецификации, используется свойство интерфейса стиля спецификации [ISpecificationStyle](ispecificationstyle.html)[ISpecificationStyle::Columns](ispecificationstyle_columns.html) или свойство интерфейса стиля раздела спецификации [ISpecificationSectionStyle](ispecificationsectionstyle.html). [ISpecificationSectionStyle::Columns](ispecificationsectionstyle_columns.html).

2\. Чтобы получить коллекцию стилей дополнительных колонок спецификации, используется свойство интерфейса стиля спецификации [ISpecificationStyle](ispecificationstyle.html)[ISpecificationStyle::AdditionalColumns](ispecificationstyle_additionalcolumns.html) или свойство интерфейса стиля раздела спецификации [ISpecificationSectionStyle](ispecificationsectionstyle.html). [ISpecificationSectionStyle::AdditionalColumns](ispecificationsectionstyle_additionalcolumns.html).
