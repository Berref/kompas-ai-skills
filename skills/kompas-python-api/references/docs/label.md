# Создание ярлыка для запуска справки

[Инструкция по созданию справки HTML для приложений](help_for_applications.html) |  Scroll [ [ ](help_for_applications.html "На уровень выше")](-web---content-.html "К предыдущему разделу")  
---|---  
  
Для вызова справки нужно передать параметры командной строки:

/a - приложение

/c - локаль

/v - версия

Пример:

...\ASCON\KOMPAS-3D v22\Bin\Ascon.HelpCall.exe /a=KOMPAS /c=ru-RU /v=21
