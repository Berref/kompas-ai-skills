double yc,

double rad,

long style);

Входные параметры:

xc, yc | \- координаты центра окружности,  
---|---  
rad | \- радиус окружности,  
style | \- стиль линии.

указатель на окружность | \- в случае удачного завершения,

0 | \- в случае неудачи.
