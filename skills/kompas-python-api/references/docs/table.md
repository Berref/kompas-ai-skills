Аналог данной функции при использовании Automation - метод [ksDocument2D::ksTable](ksdocument2d_kstable.html).

Синтаксис:

reference Table (void);

Возвращаемое значение:

указатель на таблицу | \- в случае удачного завершения,  
---|---  
0 | \- в случае неудачи.  
  
Примечание:

1\. После вызова функции и далее до вызова функции [EndObj](endobj.html) объекты чертежа (включая вертикальные и горизонтальные отрезки и тексты) будут объединены в таблицу.

2\. Таблица может быть регулярной и нерегулярной.

3\. Допустимые стили линии для отрезков таблицы:

– 1 - основная,

– 2 - тонкая,

– 7 - утолщенная,

– 0 - невидимая.

(отсутствуют)
