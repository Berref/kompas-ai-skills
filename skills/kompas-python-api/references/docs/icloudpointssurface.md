Иерархия:

IDispatch

[IKompasAPIObject](ikompasapiobject.html)

[IModelObject](imodelobject.html)

[ICloudPointsSurface](icloudpointssurface.html)

[ILocalCSObject](ilocalcsobject.html)

Интерфейс можно получить у интерфейса коллекции поверхностей по пласту (облаку точек) с помощью свойства [ICloudPointsSurfaces::CloudPointsSurface](icloudpointssurfaces_cloudpointssurface.html) или метода [ICloudPointsSurfaces::CloudPointsSurface](icloudpointssurfaces_cloudpointssurface.html).

С помощью метода [IUnknown::QueryInterface](recomendation.html) у интерфейса можно получить интерфейс подчиненного объекта ЛСК [ILocalCSObject](ilocalcsobject.html).
