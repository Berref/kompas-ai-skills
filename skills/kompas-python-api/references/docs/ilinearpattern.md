Интерфейс используется для операций:

o3d_meshCopy | 35 | Массив операций по сетке  
---|---|---  
o3d_meshPartArray | 39 | Массив компонентов по сетке для сборки  
o3d_AuxMeshCopy | 504 | Массив вспомогательной геометрии по сетке  
o3d_BodiesMeshCopy | 528 | Массив тел по сетке  
  
Интерфейс можно получить в коллекции массивов [IFeaturePatterns](ifeaturepatterns.html).
