Аналог данной функции при использовании Automation - метод [ksSpecification::ksDeleteSpcDescription](ksspecification_ksdeletespcdescription.html).

Синтаксис:

int ksDeleteSpcDescription (reference pDoc,

int index);

Входной параметр:

pDoc | \- указатель на документ,  
---|---  
index | \- индекс (номер) описания спецификации в документе.  
  
Возвращаемое значение:

1 | \- в случае удачного завершения,  
---|---  
0 | \- в случае неудачи.  
  
Подразделы:

(отсутствуют)
