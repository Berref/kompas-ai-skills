Аналог данной функции при использовании Automation - метод [ksDocument2D::ksBase](ksdocument2d_ksbase.html).

Синтаксис:

reference Base (BaseParam *basePar);

Выходной параметр:

basePar | \- указатель на структуру параметров обозначения базы [BaseParam](structbaseparam.html).  
---|---  
  
Возвращаемое значение:

указатель на обозначение базы | \- в случае удачного завершения,  
---|---  
0 | \- в случае неудачи.  
  
Примечание.

При использовании Unicode следует использовать функцию [BaseW](basew.html).
