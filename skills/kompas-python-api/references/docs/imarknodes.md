Интерфейс коллекции узлов для вставки дополнительных марок.

Иерархия:

[IKompasAPIObject](ikompasapiobject.html)

[IKompasCollection](ikompascollection.html)

[IMarkNodes](imarknodes.html)

Описание:

Интерфейс позволяет получать и создавать дополнительные узлы для вставки марок.

Примечание:

Получить интерфейс коллекции марок можно, используя методы [IStraightAxis::MarkNodes](istraightaxis_marknodes.html), [IArcAxis::MarkNodes](iarcaxis_marknodes.html), [IMarkNode::MarkNodes](imarknode_marknodes.html).
