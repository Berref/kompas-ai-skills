Аналог данной функции при использовании Automation - метод [ksDataBaseObject::ksConnectDB](ksdatabaseobject_ksconnectdb.html).

Синтаксис:

int ConnectDB (reference bd, char * dataBaseName);

Входные параметры:

bd | \- указатель на блок заголовка, созданный при помощи функции [CreateDB](createdb.html).  
---|---  
dataBaseName | \- имя БД (для базы данных, доступной через интерфейс [ODBC](odbc.html) \- имя БД в администраторе ODBC, для базы данных [текстового формата](loa.html) \- имя файла).  
  
Возвращаемое значение:

1 | \- в случае успешного завершения,  
---|---  
0 | \- в случае неудачи.  
  
Примечание:

1\. Функция связывает блок заголовка с указателем bd и базу данных с именем dataBaseName. Если база данных представлена в виде текстового файла, то функция работает аналогично стандартной функции WINDOWS OpenFile. При режиме работы через ODBC-интерфейс имя базы данных задается в файле ODBC.INI, содержащем список определенных баз данных.

2\. При использовании Unicode следует использовать функцию [ConnectDBW](connectdbw.html).
