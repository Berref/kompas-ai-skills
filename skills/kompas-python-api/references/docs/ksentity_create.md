Примечание:

Данный метод необходимо вызвать для создания объекта в модели после создания интерфейса с помощью метода [NewEntity](kspart_newentity.html) и изменения параметров создаваемого объекта.

Если до вызова данного метода свойства объекта не изменены, то объект создается с параметрами, принятыми по умолчанию.

Если объект уже создан, то функция вызовет метод [Update](ksentity_update.html).
