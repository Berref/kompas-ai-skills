Интерфейс событий объектов спецификации.

Предназначен для того, чтобы следить и при необходимости управлять редактированием объектов спецификации.

Источником событий для подписки на данный интерфейс являются объекты:

•[ISpecificationObject](ispecificationobject.html) \- Интерфейс объекта спецификации (базового или вспомогательного),

•[ISpecificationBaseObjects](ispecificationbaseobjects.html) \- Интерфейс коллекции базовых объектов спецификации,

•[ISpecificationCommentObjects](ispecificationcommentobjects.html) \- Интерфейс коллекции вспомогательных объектов спецификации.
