# RasterParam - Структура параметров растрового объекта

[Структуры параметров и константы](3d_define.html) > [Структуры параметров документов ](bk1829760.html) |  Scroll [ [ [ ](structrasterparamw.html "К следующему разделу")](bk1829760.html "На уровень выше")](structrasterformatparamw.html "К предыдущему разделу")  
---|---  
  
Аналог данных параметров при использовании Automation - интерфейс [ksRasterParam](ksrasterparam.html).

[PlacementParam](structplacementparam.html) | place | структура местоположения,  
---|---|---  
char | fileName [MAX_TEXT_LENGTH] | полный путь к файлу,  
unsigned char | embeded | признак внедрения или ссылки (1 - внедрять данные в объект, 0 - связывать объект файлом на диске).  
  
Примечание:

1\. Значение параметра embeded = 0 в данный момент не используется (связь растрового объекта с файлом на диске в КОМПАС-ГРАФИК не реализована).

2\. При использовании Unicode следует использовать структуру параметров [RasterParamW](structrasterparamw.html).
