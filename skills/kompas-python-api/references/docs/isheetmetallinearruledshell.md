Иерархия:

IDispatch

[ISheetMetalLinearRuledShell](isheetmetallinearruledshell.html)

Данный интерфейс можно получить из коллекции обечаек, полученной с помощью свойства [ISheetMetalContainer::SheetMetalLinearRuledShells](isheetmetalcontainer_sheetmetallinearruledshells.html), с помощью метода [ISheetMetalBodies::Add](isheetmetalbodies_add.html) или свойства [ISheetMetalBodies::SheetMetalBody](isheetmetalbodies_sheetmetalbody.html).

Интерфейс является дополнительным для [ISheetMetalBody](isheetmetalbody.html), [ISheetMetalRuledShell](isheetmetalruledshell.html).
