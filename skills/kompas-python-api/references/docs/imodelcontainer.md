Интерфейс контейнера трехмерных объектов.

Иерархия:

IDispatch

[IModelContainer](imodelcontainer.html)

Описание.

Интерфейс позволяет работать с коллекциями 3D-объектов, входящих в состав 3D-объекта.

Примечание.

Интерфейс контейнера является дополнительным к интерфейсу [IPart7](ipart7.html). Данный интерфейс можно получить от IPart7 посредством вызова метода [IUnknown::QueryInterface (const GUID far& iid, void** pif)](recomendation.html);
