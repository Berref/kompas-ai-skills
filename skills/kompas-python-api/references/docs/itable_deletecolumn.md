Синтаксис Automation:

Синтаксис COM:

Входные параметры:

ColN | \- номер удаляемого столбца.  
---|---  
  
Возвращаемое значение:

TRUE | \- в случае успеха,  
---|---  
FALSE | \- в случае неудачи.

Позволяет удалить столбец из таблицы.
