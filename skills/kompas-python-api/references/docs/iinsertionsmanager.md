Интерфейс менеджера вставок фрагментов и видов.

Иерархия:

IDispatch

[IInsertionsManager](iinsertionsmanager.html)

Описание:

Интерфейс позволяет создавать и получать вставки фрагментов и видов.

Примечание:

Интерфейс является дополнительным к интерфейсу документа [IKompasDocument](ikompasdocument.html). Интерфейс можно получить посредством вызова метода [IUnknown::QueryInterface (const GUID far& iid, void** pif)](recomendation.html).
