Интерфейс параметров столбца табличного атрибута.

Иерархия:

[IKompasAPIObject](ikompasapiobject.html)

[IColumnInfo](icolumninfo.html)

Примечание:

1\. Интерфейс позволяет задавать параметры столбца табличного атрибута.

2\. Интерфейс можно получить следующими способами:

•у интерфейса типа атрибута с помощью свойства [IAttributeType::ColumnInfo](iattributetype_columninfo.html) и метода [IAttributeType::AddColumn](iattributetype_addcolumn.html).

•для столбца записи - с помощью свойства [IColumnInfo::RecordColumnInfo](icolumninfo_recordcolumninfo.html) и метода [IColumnInfo::AddRecordColumn](icolumninfo_addrecordcolumn.html).
