Синтаксис Automation:

long ksTable();

Возвращаемое значение:

указатель на таблицу | \- в случае удачного завершения,  
---|---  
0 | \- в случае неудачи.  
  
Примечание:

Таблица - составной объект. Объекты, вводимые между операторами [ksDocument2D::ksTable](ksdocument2d_kstable.html) и [ksDocument2D::ksEndObj](ksdocument2d_ksendobj.html), принадлежат таблице. Допустимые объекты - отрезки, тексты. Отрезки должны быть вертикальными и горизонтальными.

ksDocument2D::ksEndObj возвращает указатель на таблицу.

Допустимые стили линии для отрезков таблицы:

1 - основная,

2 - тонкая,

7 - утолщенная,

0 - невидимая.
