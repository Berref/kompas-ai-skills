Аналог данной функции при использовании Automation - метод [ksDataBaseObject::ksRDouble](ksdatabaseobject_ksrdouble.html).

Синтаксис:

int LODBC_FUNC RDouble (LPWSTR name);

Входной параметр:

name | \- имя поля.  
---|---  
  
Возвращаемое значение:

1 | \- в случае успешного завершения,  
---|---  
0 | \- в случае неудачи.  
  
Примечание:

Параметр name действителен только при работе с текстовыми базами данных.

Подразделы:

(отсутствуют)
