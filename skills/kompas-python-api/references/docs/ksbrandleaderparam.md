Интерфейс параметров линии-выноски для обозначения клеймения.

Аналог данных параметров при использовании API экспортных функций - [BrandLeaderParam](structbrandleaderparam.html).

Примечания:

1\. Если cText0 = 0 или cText1 = 0 или cText2 = 0, то соответствующий текст на линии-выноске отсутствует.

2\. Указатель на интерфейс можно получить при помощи метода [KompasObject::GetParamStruct](kompasobject_getparamstruct.html).
