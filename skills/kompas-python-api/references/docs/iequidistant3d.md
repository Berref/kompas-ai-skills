Эквидистанта 3D.

Иерархия:

[IKompasAPIObject](ikompasapiobject.html)

[IModelObject](imodelobject.html)

[IEquidistant3D](iequidistant3d.html)

Описание:

Позволяет задавать параметры эквидистанты в 3D документе.

Примечание:

1\. Интерфейс можно получить у коллекции 3D-эквидистант, используя свойство [IEquidistants3D::Equidistant3D](iequidistants3d_equidistant3d.html) или метод [IEquidistants3D::Add](iequidistants3d_add.html).

2\. После задания параметров эквидистанты требуется вызвать метод [IModelObject::Update](imodelobject_update.html).
