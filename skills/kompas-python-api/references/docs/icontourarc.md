Интерфейс сегмента контура - дуги.

Иерархия:

IDispatch

[IKompasAPIObject](ikompasapiobject.html)

[IContourSegment](icontoursegment.html)

[IContourArc](icontourarc.html)

Описание:

Интерфейс позволяет создавать и редактировать сегмент контура – дугу.

Примечание:

Интерфейс можно получить следующими способами:

•у интерфейса контура с помощью свойства [IContour::Segment](icontour_segment.html) или метода [IContour::AddSegment](icontour_addsegment.html).

•у интерфейса [IContourSegment](icontoursegment.html) с помощью метода [IUnknown::QueryInterface](recomendation.html).
