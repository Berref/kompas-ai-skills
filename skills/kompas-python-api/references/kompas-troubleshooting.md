# Типовые ошибки при работе с API КОМПАС-3D из Python

## 1. `LineSegment` вместо `LineSegments`

**Симптом:** `AttributeError` или отсутствие свойства при обращении к коллекции отрезков.

**Причина:** в цепочке `IDrawingContainer` коллекция называется `LineSegments` (во множественном числе).

**Решение:** заменить `LineSegment` на `LineSegments`.

## 2. `EnsureModule` не находит библиотеку типов

**Симптом:** ошибка на этапе `gencache.EnsureModule(...)`.

**Причина:** несовпадение версии Компаса или разрядности Python и Компаса.

**Решение:** проверить установку Компаса и разрядность Python (должна совпадать).

## 3. Объект не появляется на экране после изменения

**Симптом:** геометрия добавлена, но не отображается.

**Причина:** не вызван метод `.Update()` после изменения свойств.

**Решение:** всегда вызывать `.Update()` после заполнения координат и свойств.

## 4. `CoInitialize` / `CoUninitialize`

**Симптом:** нестабильная работа COM или утечки при длительных скриптах.

**Решение:** явно вызывать `pythoncom.CoInitialize()` в начале и `pythoncom.CoUninitialize()` в конце, особенно в фоновых потоках.
